La voix passive du verbe sain

تَمَارِين
👋 Instructions : ces exercices accompagnent la leçon « La voix passive du verbe sain ». Rappel : passé فُعِلَ, présent يُفْعَلُ ; le complément d'objet devient sujet (nominatif) et le verbe s'accorde avec lui.

1Actif ou passif ?

Indiquez si le verbe est à l'actif ou au passif

  1. كَتَبَ الْوَلَدُ الدَّرْسَ →
  2. كُتِبَ الدَّرْسُ →
  3. يُفْتَحُ الْبَابُ →
  4. يَفْتَحُ الْحَارِسُ الْبَابَ →
  5. سُمِعَ الْخَبَرُ →
  6. سَمِعَ النَّاسُ الْخَبَرَ →

2Former le passif

Écrivez le passif du verbe, au passé puis au présent (3e personne du masculin singulier), avec les voyelles

ActifPassif au passéPassif au présent
دَرَسَ ـ يَدْرُسُ
شَرِبَ ـ يَشْرَبُ
مَنَعَ ـ يَمْنَعُ
ضَرَبَ ـ يَضْرِبُ
فَهِمَ ـ يَفْهَمُ
فَتَحَ ـ يَفْتَحُ

3De l'actif au passif

Transformez chaque phrase à la voix passive (avec les voyelles, sans exprimer l'auteur)

  1. فَتَحَ الْحَارِسُ الْبَابَ →
  2. كَتَبَ الطَّالِبُ الدَّرْسَ →
  3. شَرِبَ الْوَلَدُ الْعَصِيرَ →
  4. كَتَبَتِ الْمُعَلِّمَةُ الرِّسَالَةَ →
  5. يَدْرُسُ الطُّلَّابُ الدَّرْسَ →
  6. سَمِعَ النَّاسُ الْخَبَرَ →

4Du passif à l'actif

Retrouvez une phrase active possible, en choisissant vous-même l'auteur (avec les voyelles)

  1. فُتِحَ الْكِتَابُ →
  2. يُكْتَبُ الدَّرْسُ →
  3. شُرِبَ الْمَاءُ →
  4. دُرِسَتِ الْقِصَّةُ →

5L'accord du verbe passif

Complétez avec le passif de كَتَبَ (passé), bien accordé

  1. الدَّرْسُ.
  2. الرِّسَالَةُ.
  3. الرَّسَائِلُ.
  4. الدُّرُوسُ.
  5. الرِّسَالَةُ (verbe après le sujet).
  6. الدَّرْسَانِ (verbe après le sujet).

6Événement ou état ?

Complétez avec le verbe passif ou le participe passif, selon le sens

  1. La porte est ouverte → الْبَابُ
  2. La porte a été ouverte → الْبَابُ
  3. L'entrée est interdite → الدُّخُولُ
  4. La leçon a été écrite → الدَّرْسُ
  5. La lettre est écrite → الرِّسَالَةُ

7Le passif avec تَمَّ

Récrivez chaque phrase avec تَمَّ + maṣdar (aidez-vous du maṣdar donné)

  1. فُتِحَ الْبَابُ (فَتْحٌ) →
  2. كُتِبَتِ الرِّسَالَةُ (كِتَابَةٌ) →
  3. دُرِسَ الدَّرْسُ (دِرَاسَةٌ) →
  4. مُنِعَ الدُّخُولُ (مَنْعٌ) →

8Conjugaison du passif

Conjuguez شَكَرَ (remercier) au passif du passé

  1. هُوَ →
  2. هِيَ →
  3. هُمْ →
  4. أَنْتَ →
  5. أَنْتِ →
  6. أَنَا →

9Trouvez l'erreur

Corrigez la phrase fautive (voyelle ou case)

  1. فُتِحَ الْبَابَ →
  2. كُتِبَ الرِّسَالَةُ →
  3. يَكْتَبُ الدَّرْسُ (sens passif voulu) →
  4. كُتِبُوا الدَّرْسُ →

10Traduisez en arabe

Écrivez les phrases en arabe (avec les voyelles)

  1. La leçon a été étudiée →
  2. Le jus a été bu →
  3. La porte n'a pas été ouverte →
  4. La lettre sera écrite (utilisez le futur avec سَـ) →
  5. On t'a remercié (à un homme) →

11Compréhension

Lisez et répondez

فُتِحَتِ الْمَكْتَبَةُ صَبَاحًا. كُتِبَتِ الْأَسْمَاءُ، ثُمَّ دُرِسَتِ الْقِصَّةُ. وَلَمْ يُسْمَعْ صَوْتٌ.

Questions :

  1. Traduisez le texte en français.
  2. Mettez la première phrase à l'actif en choisissant un auteur.
  3. Pourquoi كُتِبَتِ est-il au féminin singulier alors que الْأَسْمَاءُ est un pluriel ?
  4. Quel est le mode du verbe dans وَلَمْ يُسْمَعْ ?
💡 Conseil : devant un verbe non voyellé, regardez ce qui le suit : si un complément d'objet à l'accusatif apparaît, le verbe est actif ; s'il n'y a qu'un nom au nominatif sans auteur, il est probablement passif.
