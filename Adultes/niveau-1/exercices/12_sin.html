Instructions : la lettre est étudiée sous sa forme isolée. Munissez-vous d'un crayon : les exercices progressent de la reconnaissance vers l'écriture.

4Je prononce la lettre

Son : comme le « s » de « soleil ».

Avec le signe ـَ (la fatḥa, étudiée au niveau 2), la lettre est suivie du son « a » : سَ

Lisez chaque lettre à voix haute avec l'enseignant.

زَصَتَسَسَضَسَصَ

L'enseignant prononce une lettre de chaque ligne : cochez celle que vous entendez.

  1. سَ شَ
  2. صَ سَ
  3. سَ ضَ
  4. شَ سَ

5Je trace la lettre

Forme : trois petites dents suivies d'une courbe ; aucun point.

Repassez au crayon sur les modèles gris, puis écrivez la lettre dans la dernière ligne.

Corrigé (enseignant)
  • Exercice 1 : 2, 2, 2 fois par ligne (de haut en bas).
  • Exercice 2 : س : aucun point ; ش : trois points au-dessus ; ص : aucun point ; ض : un point au-dessus. Lettres différentes, comptées depuis la droite : 1, 6, 2.
  • Exercice 3 : س = sîn ; ش = chîn ; ص = ṣâd ; ض = ḍâd.
  • Exercice 4 : l'enseignant choisit librement dans chaque couple ; vérifier la réponse oralement.
  • Exercice 7 : 8 lettres dans la grille ; lettre manquante : س.
