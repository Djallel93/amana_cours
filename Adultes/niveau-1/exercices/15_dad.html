Exercices — lettre ض (ḍâd)

Instructions : la lettre est étudiée sous sa forme isolée. Munissez-vous d'un crayon : les exercices progressent de la reconnaissance vers l'écriture.

4Je prononce la lettre

Son : un « d » emphatique : la langue se relève vers le palais, le son est plus grave et plus plein que celui de د.

Avec le signe ـَ (la fatḥa, étudiée au niveau 2), la lettre est suivie du son « a » : ضَ

Lisez chaque lettre à voix haute avec l'enseignant.

اوَضَكَضَضَظَشَ

L'enseignant prononce une lettre de chaque ligne : cochez celle que vous entendez.

  1. ضَ صَ
  2. ظَ ضَ
  3. ضَ شَ
  4. صَ ضَ

5Je trace la lettre

Forme : la même boucle que ص ; un point au-dessus.

Repassez au crayon sur les modèles gris, puis écrivez la lettre dans la dernière ligne.

Corrigé (enseignant)
  • Exercice 1 : 3, 3, 2 fois par ligne (de haut en bas).
  • Exercice 2 : ض : un point au-dessus ; ص : aucun point ; ظ : un point au-dessus ; ش : trois points au-dessus. Lettres différentes, comptées depuis la droite : 4, 5, 2.
  • Exercice 3 : ض = ḍâd ; ص = ṣâd ; ظ = ẓâ’ ; ش = chîn.
  • Exercice 4 : l'enseignant choisit librement dans chaque couple ; vérifier la réponse oralement.
  • Exercice 7 : 8 lettres dans la grille ; lettre manquante : ض.
