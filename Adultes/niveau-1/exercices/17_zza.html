4Je prononce la lettre

Son : un « z » emphatique prononcé la langue entre les dents, avec un son plus grave et plus plein que celui de ذ.

Avec le signe ـَ (la fatḥa, étudiée au niveau 2), la lettre est suivie du son « a » : ظَ

Lisez chaque lettre à voix haute avec l'enseignant.

L'enseignant prononce une lettre de chaque ligne : cochez celle que vous entendez.

  3. ظَ غَ
  4. طَ ظَ

5Je trace la lettre

Repassez au crayon sur les modèles gris, puis écrivez la lettre dans la dernière ligne.

Corrigé (enseignant)
  • Exercice 1 : 2, 2, 3 fois par ligne (de haut en bas).
  • Exercice 2 : ظ : un point au-dessus ; ط : aucun point ; ض : un point au-dessus ; غ : un point au-dessus. Lettres différentes, comptées depuis la droite : 3, 1, 1.
  • Exercice 3 : ظ = ẓâ’ ; ط = ṭâ’ ; ض = ḍâd ; غ = ghayn.
  • Exercice 4 : l'enseignant choisit librement dans chaque couple ; vérifier la réponse oralement.
  • Exercice 7 : 6 lettres dans la grille ; lettre manquante : ظ.
