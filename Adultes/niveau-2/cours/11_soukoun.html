Cours 11 — Le سُكُونٌ

Le السُّكُون est un petit rond placé sur une consonne : il indique que cette consonne n'est suivie d'aucune voyelle. La syllabe se ferme sur cette consonne. Un mot arabe ne commence jamais par une consonne sans voyelle.

Remarque : le nom de ce signe commence par ال (l’article « le / la »). Cette notion sera vue au niveau 3 : pour l’instant, lisez simplement le mot tel qu’il est écrit.

Objectifs

  • Lire une syllabe fermée par un سُكُونٌ
  • Lire des mots courts contenant un سُكُونٌ

Prérequis

Les voyelles brèves (فَتْحَةٌ, ضَمَّةٌ, كَسْرَةٌ).

Nouveaux concepts

  • Le سُكُونٌ : absence de voyelle
  • La syllabe fermée : consonne + voyelle + consonne

Activités guidées

  1. Lire le mot. L'enseignant lit un mot ; repérez le سُكُونٌ et dites quelle consonne il ferme.
  2. Compter les syllabes. Frappez dans les mains à chaque syllabe.
  3. Dictée de syllabes fermées. L'enseignant dit une syllabe ; écrivez-la avec le سُكُونٌ.

Exercices

Dans le fichier de chaque lettre :
