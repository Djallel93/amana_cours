Corrigé (enseignant)
  • Exercice 1 : ط dans طريق : début ; و dans وطن : début ; و dans لون : milieu ; ج dans مسجد : milieu ; س dans سهل : début.
  • Exercice 2 : بـ : initiale ; ـجـ : médiane ; مـ : initiale ; خ : isolée ; ـط : finale. (Pour une lettre qui ne se lie pas à la suivante, la forme initiale s'écrit comme la forme isolée : accepter les deux réponses.)
  • Exercice 3 : شمس = ش م س ; حديث = ح د ي ث ; مكتب = م ك ت ب.
  • Exercice 4 : م ط ر = مطر ; ي د = يد ; ف ر ا ش = فراش.
