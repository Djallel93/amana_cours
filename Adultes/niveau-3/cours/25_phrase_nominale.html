Cours 25 — La phrase nominale : le meuble est…

Commence la partie E : lire et écrire des phrases. On construit des phrases nominales complètes, sans verbe, avec un nom défini et un adjectif indéfini qui s’accorde avec lui.

Objectifs

  • Lire une phrase nominale
  • Accorder l’adjectif avec le nom (masculin / féminin)
  • Distinguer هَٰذِهِ طَاوِلَةٌ et هَٰذِهِ الطَّاوِلَةُ كَبِيرَةٌ

Prérequis

Séances 17 à 23.

Nouveaux concepts

  • Nom défini + adjectif indéfini = phrase
  • L’adjectif s’accorde : ـَةٌ pour le féminin
  • هَٰذَا / هَٰذِهِ + nom défini

Explication

Une phrase nominale se compose de deux éléments : un nom défini et un mot indéfini qui dit quelque chose de lui. L’arabe ne dit pas « est » : الطَّاوِلَةُ كَبِيرَةٌ se traduit « la table est grande ». L’adjectif s’accorde avec le nom : s’il est féminin, il se termine par ة.

PhraseSens
الْمِصْبَاحُ جَدِيدٌla lampe est neuve
الطَّاوِلَةُ كَبِيرَةٌla table est grande
الْخِزَانَةُ قَدِيمَةٌl’armoire est ancienne
التِّلْفَازُ صَغِيرٌla télévision est petite

Montrer un objet

هَٰذَا / هَٰذِهِ suivi d’un nom indéfini signifie « c’est un… » (هَٰذِهِ طَاوِلَةٌ). Suivi d’un nom défini, il signifie « ce… » (هَٰذِهِ الطَّاوِلَةُ كَبِيرَةٌ, « cette table est grande »).

Activités guidées

  1. L’enseignant montre un objet et dit une phrase : la classe la répète.
  2. On transforme طَاوِلَةٌ كَبِيرَةٌ (groupe) en الطَّاوِلَةُ كَبِيرَةٌ (phrase).
  3. Par deux : décrire un objet de la classe.
  4. Lecture des mots de la séance.

Les mots de la séance en contexte

Visite d’une petite chambre : chaque objet est d’abord montré avec هَٰذَا ou هَٰذِهِ, puis décrit par une phrase nominale, sans verbe, où l’adjectif s’accorde avec le nom.

Texte

هَٰذِهِ غُرْفَةٌ صَغِيرَةٌ.
هَٰذَا فِرَاشٌ. الْفِرَاشُ جَدِيدٌ.
هَٰذِهِ مِرْآةٌ. الْمِرْآةُ قَدِيمَةٌ.
هَٰذَا مِصْبَاحٌ. الْمِصْبَاحُ أَبْيَضُ.
هَٰذِهِ وِسَادَةٌ. الْوِسَادَةُ كَبِيرَةٌ.
هَٰذِهِ سِتَارَةٌ. السِّتَارَةُ جَدِيدَةٌ.

Traduction
Voici une petite chambre.
Voici un matelas. Le matelas est neuf.
Voici un miroir. Le miroir est ancien.
Voici une lampe. La lampe est blanche.
Voici un coussin. Le coussin est grand.
Voici un rideau. Le rideau est neuf.

Chaque ligne, de la deuxième à la dernière, joue sur le même contraste. Après هَٰذِهِ ou هَٰذَا, le nom reste indéfini : هَٰذِهِ وِسَادَةٌ signifie « voici un coussin ». Dès que ce nom reçoit l’article, il devient le sujet d’une phrase complète : الْوِسَادَةُ كَبِيرَةٌ, « le coussin est grand », sans aucun mot pour traduire « est ».

L’adjectif prend le genre du nom qu’il qualifie : جَدِيدٌ avec le masculin الْفِرَاشُ, قَدِيمَةٌ avec le féminin الْمِرْآةُ, جَدِيدَةٌ avec le féminin السِّتَارَةُ. La première ligne, où غُرْفَةٌ صَغِيرَةٌ reste un simple groupe indéfini, montre que sans article on obtient seulement « une petite chambre ».

Mise en pratique

  1. Relevez les deux phrases nominales de la ligne 4 et dites laquelle contient le sujet défini.
  2. Dans la ligne 3, remplacez الْمِرْآةُ par الْفِرَاشُ. Que devient l’adjectif ?
  3. Quels objets du texte sont décrits comme neufs ? Lequel est ancien ?
  4. Pour dire « le réfrigérateur est grand », faut-il choisir كَبِيرٌ ou كَبِيرَةٌ après الثَّلَّاجَةُ ? Et après التِّلْفَازُ ?
Corrigé
  1. هَٰذَا مِصْبَاحٌ (« voici une lampe ») montre l’objet ; الْمِصْبَاحُ أَبْيَضُ (« la lampe est blanche ») est la phrase nominale dont le sujet, الْمِصْبَاحُ, porte l’article.
  2. On obtient الْفِرَاشُ قَدِيمٌ : le nom est masculin, l’adjectif perd donc le ة.
  3. Le matelas (الْفِرَاشُ) et le rideau (السِّتَارَةُ) sont neufs ; le miroir (الْمِرْآةُ) est ancien.
  4. On dit الثَّلَّاجَةُ كَبِيرَةٌ, car le nom est féminin, mais التِّلْفَازُ كَبِيرٌ, car le nom est masculin.
