Corrigé (enseignant)
  • Exercice 1 : غُرْفَةٌ → ة ; بَيْتٌ → ت ; وَجْهٌ → ه ; مُوسَى → ى ; مَدْرَسَةٌ → ة
  • Exercice 2 : 1. قِطَارًا ; 2. سَيَّارَةً ; 3. مَقْهًى
  • Exercice 3 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 4 : س ف ي ن ة → سَفِينَةٌ ; ن ا ف ذ ة → نَافِذَةٌ ; ب ي ت → بَيْتٌ ; ع م ة → عَمَّةٌ ; ص ف → صَفٌّ
  • Exercice 5 : مَلَاكٌ → م - ل - ا - ك ; مَطَارٌ → م - ط - ا - ر ; كُوبٌ → ك - و - ب ; صَوْتٌ → ص - و - ت
  • Exercice 6 : هَاتِفٌ ; رَقْمٌ ; صَغِيرٌ ; ذَٰلِكَ ; قَدِيمٌ ; شَارِعٌ
  • Exercice 7 : جَدِيدٌ = neuf ; سَلْمَى = Salma ; جَدَّةٌ = grand-mère ; هِيَ = elle ; لَوْحٌ = tableau ; طَالِبَةٌ = étudiante
  • Exercice 8 : il = هُوَ ; porte = بَابٌ ; parole = كَلَامٌ ; chaise = كُرْسِيٌّ ; Layla = لَيْلَى
