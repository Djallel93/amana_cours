Exercices niveau 3 — Cours 4 : Lire un nom et son adjectif

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Pour une classe rapide, deux pages peuvent être traitées dans la même séance.

Nom et prénom :   Date :

Construire et déconstruire

✍️ Pour écrire : Écrivez chaque mot en entier, de droite à gauche. Ajoutez ensuite les points, puis les voyelles et les autres signes. Voir l’aide « Bien écrire ».

1Construire des motsNotion : construction

Assemblez les lettres pour écrire chaque mot, avec ses voyelles.

طويل

Sens : long

كبير

Sens : grand

جديد

Sens : neuf

سهل

Sens : facile

2Découper en syllabesNotion : déconstruction

Découpez chaque mot en syllabes : écrivez les syllabes séparées par un tiret.

قَصِيرٌ — court

صَغِيرٌ — petit

قَدِيمٌ — ancien

صَعْبٌ — difficile

3Remettre les groupes dans l’ordreNotion : construction de phrase

Remettez les deux mots dans l’ordre : le nom d’abord, l’adjectif ensuite.

قَدِيمٌكِتَابٌ
قَصِيرٌقَلَمٌ
بَعِيدٌبَيْتٌ

Lire

4Lire les mots de la séanceNotion : lecture

Lisez à voix haute, sans épeler.

طَوِيلٌقَصِيرٌكَبِيرٌصَغِيرٌجَدِيدٌقَدِيمٌسَهْلٌصَعْبٌقَرِيبٌبَعِيدٌ

5Lire des phrasesNotion : lecture

Lisez chaque phrase à voix haute, puis donnez-en le sens.

  1. كِتَابٌ جَدِيدٌ
  2. قَلَمٌ طَوِيلٌ
  3. دَرْسٌ سَهْلٌ
  4. بَابٌ كَبِيرٌ
  5. كُرْسِيٌّ قَدِيمٌ
  6. صُنْدُوقٌ صَغِيرٌ

Dicter et écrire

6Dictée de motsNotion : dictée

7Dictée de phrasesNotion : dictée

Votre enseignant dicte 2 phrases. Écrivez-les, avec leurs voyelles.

Corrigé (enseignant)
  • Exercice 1 : ط و ي ل → طَوِيلٌ ; ك ب ي ر → كَبِيرٌ ; ج د ي د → جَدِيدٌ ; س ه ل → سَهْلٌ
  • Exercice 2 : قَصِيرٌ → قَ – صِي – رٌ (3) ; صَغِيرٌ → صَ – غِي – رٌ (3) ; قَدِيمٌ → قَ – دِي – مٌ (3) ; صَعْبٌ → صَعْ – بٌ (2)
  • Exercice 3 : كِتَابٌ قَدِيمٌ (un livre ancien) ; قَلَمٌ قَصِيرٌ (un stylo court) ; بَيْتٌ بَعِيدٌ (une maison lointaine)
  • Exercice 4 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 5 : traductions : 1. un livre neuf ; 2. un long stylo ; 3. une leçon facile ; 4. une grande porte ; 5. une chaise ancienne ; 6. une petite boîte
  • Exercice 6 : قَصِيرٌ ; صَغِيرٌ ; قَدِيمٌ ; صَعْبٌ ; بَعِيدٌ
  • Exercice 7 : كِتَابٌ جَدِيدٌ ; قَلَمٌ طَوِيلٌ
  • Exercice 8 : طَوِيلٌ = long ; قَصِيرٌ = court ; كَبِيرٌ = grand ; صَغِيرٌ = petit ; جَدِيدٌ = neuf ; قَدِيمٌ = ancien ; سَهْلٌ = facile ; صَعْبٌ = difficile
  • Exercice 9 : grand = كَبِيرٌ ; neuf = جَدِيدٌ ; facile = سَهْلٌ ; proche = قَرِيبٌ
