Exercices niveau 3 — Cours 12 : La hamza au milieu du mot

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Pour une classe rapide, deux pages peuvent être traitées dans la même séance.

Nom et prénom :   Date :

Reconnaître et classer

1Trouver le support de la hamzaNotion : choix

Choisissez le support de la hamza : أ, ؤ, ئ ou ء (seule sur la ligne).

  1. رَ◌ْسٌ — voyelle avant : fatḥa ; voyelle de la hamza : sukūn
    أ ؤ ئ ء
  2. سُ◌َالٌ — voyelle avant : ḍamma ; voyelle de la hamza : fatḥa
    أ ؤ ئ ء
  3. بِ◌ْرٌ — voyelle avant : kasra ; voyelle de la hamza : sukūn
    أ ؤ ئ ء
  4. فَ◌ْرٌ — voyelle avant : fatḥa ; voyelle de la hamza : sukūn
    أ ؤ ئ ء
  5. مُ◌ْمِنٌ — voyelle avant : ḍamma ; voyelle de la hamza : sukūn
    أ ؤ ئ ء
  6. مِ◌َةٌ — voyelle avant : kasra ; voyelle de la hamza : fatḥa
    أ ؤ ئ ء

Construire et déconstruire

2Construire des motsNotion : construction

Assemblez les lettres pour écrire chaque mot, avec ses voyelles.

رأس

Sens : tête

سؤال

Sens : question

بئر

Sens : puits

ذئب

Sens : loup

رئيس

Sens : chef

3Déconstruire des motsNotion : déconstruction

Séparez le mot en lettres : écrivez chaque lettre isolément, de droite à gauche.

فَأْرٌ — souris

مُؤْمِنٌ — croyant

مَسْأَلَةٌ — problème

مِئَةٌ — cent

Lire

4Lire les mots de la séanceNotion : lecture

Lisez à voix haute, sans épeler.

رَأْسٌسُؤَالٌبِئْرٌذِئْبٌفَأْرٌمُؤْمِنٌمَسْأَلَةٌمِئَةٌرَئِيسٌ

5Lire des phrasesNotion : lecture

Lisez chaque phrase à voix haute, puis donnez-en le sens.

  1. هَٰذَا رَئِيسٌ كَبِيرٌ
  2. هَٰذِهِ بِئْرٌ قَدِيمَةٌ
  3. هَٰذَا سُؤَالٌ صَعْبٌ
  4. هَٰذِهِ مَسْأَلَةٌ سَهْلَةٌ

Dicter et écrire

6Dictée de motsNotion : dictée

Votre enseignant dicte 5 mots. Écrivez-les, avec leurs voyelles.

7Dictée de phrasesNotion : dictée

Votre enseignant dicte 2 phrases. Écrivez-les, avec leurs voyelles.

Corrigé (enseignant)
  • Exercice 1 : 1. أ ; 2. ؤ ; 3. ئ ; 4. أ ; 5. ؤ ; 6. ئ
  • Exercice 2 : ر أ س → رَأْسٌ ; س ؤ ا ل → سُؤَالٌ ; ب ئ ر → بِئْرٌ ; ذ ئ ب → ذِئْبٌ ; ر ئ ي س → رَئِيسٌ
  • Exercice 3 : فَأْرٌ → ف - أ - ر ; مُؤْمِنٌ → م - ؤ - م - ن ; مَسْأَلَةٌ → م - س - أ - ل - ة ; مِئَةٌ → م - ئ - ة
  • Exercice 4 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 5 : traductions : 1. c’est un grand chef ; 2. c’est un vieux puits ; 3. c’est une question difficile ; 4. c’est un problème facile
  • Exercice 6 : رَأْسٌ ; سُؤَالٌ ; بِئْرٌ ; مُؤْمِنٌ ; رَئِيسٌ
  • Exercice 7 : هَٰذَا رَئِيسٌ كَبِيرٌ ; هَٰذِهِ بِئْرٌ قَدِيمَةٌ
  • Exercice 8 : رَأْسٌ = tête ; سُؤَالٌ = question ; بِئْرٌ = puits ; ذِئْبٌ = loup ; فَأْرٌ = souris ; مُؤْمِنٌ = croyant ; مَسْأَلَةٌ = problème ; مِئَةٌ = cent ; رَئِيسٌ = chef
  • Exercice 9 : tête = رَأْسٌ ; question = سُؤَالٌ ; puits = بِئْرٌ ; souris = فَأْرٌ ; cent = مِئَةٌ
