Exercices niveau 3 — Cours 20 : Lune ou soleil ? Lire sans se tromper

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Pour une classe rapide, deux pages peuvent être traitées dans la même séance.

Corrigé (enseignant)
  • Exercice 1 : الْكِتَابُ → lunaire ; الشَّمْسُ → solaire ; الْقَمَرُ → lunaire ; النَّجْمُ → solaire ; الْبَحْرُ → lunaire ; الطَّالِبُ → solaire ; الْمُعَلِّمُ → lunaire ; الرِّيحُ → solaire
  • Exercice 2 : أ ب ي ض → أَبْيَضُ ; أ س و د → أَسْوَدُ ; أ ح م ر → أَحْمَرُ ; أ ز ر ق → أَزْرَقُ ; ل و ن → لَوْنٌ
  • Exercice 3 : أَخْضَرُ → أ - خ - ض - ر ; أَصْفَرُ → أ - ص - ف - ر ; الثُّلَاثَاءُ → ا - ل - ث - ل - ا - ث - ا - ء ; السَّبْتُ → ا - ل - س - ب - ت ; الِاثْنَيْنِ → ا - ل - ا - ث - ن - ي - ن
  • Exercice 4 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 5 : traductions : 1. le livre est blanc ; 2. le stylo est rouge ; 3. la porte est bleue ; 4. la chaise est verte
  • Exercice 6 : 1. الْكِتَابُ ; 2. الْقَلَمُ ; 3. الْبَابُ ; 4. الطَّالِبُ ; 5. الشَّارِعُ ; 6. الدَّفْتَرُ
  • Exercice 7 : أَبْيَضُ ; أَسْوَدُ ; أَحْمَرُ ; الثُّلَاثَاءُ ; السَّبْتُ
  • Exercice 8 : الْكِتَابُ أَبْيَضُ ; الْقَلَمُ أَحْمَرُ
  • Exercice 9 : أَبْيَضُ = blanc ; أَسْوَدُ = noir ; أَحْمَرُ = rouge ; أَزْرَقُ = bleu ; أَخْضَرُ = vert ; أَصْفَرُ = jaune ; لَوْنٌ = couleur ; الثُّلَاثَاءُ = mardi ; السَّبْتُ = samedi ; الِاثْنَيْنِ = lundi
