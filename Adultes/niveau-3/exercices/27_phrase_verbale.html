Exercices niveau 3 — Cours 27 : La phrase verbale : le verbe au passé

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Pour une classe rapide, deux pages peuvent être traitées dans la même séance.

Nom et prénom :   Date :

Construire et déconstruire

1Construire la phraseNotion : construction de phrase

Remettez les mots dans l’ordre pour écrire une phrase.

الدَّرْسَكَتَبَالطَّالِبُ
الْبَابَفَتَحَالْحَارِسُ
الْمَدْرَسَةِإِلَىذَهَبَالْمُعَلِّمُ

2Découper en motsNotion : déconstruction de phrase

Découpez chaque phrase en mots : écrivez les mots séparés par une barre oblique.

جَلَسَ الْوَلَدُ عَلَى الْكُرْسِيِّ

فَهِمَ الطَّالِبُ الدَّرْسَ

3Construire des motsNotion : construction

Assemblez les lettres pour écrire chaque mot, avec ses voyelles.

كتب

Sens : il a écrit

درس

Sens : il a étudié

ذهب

Sens : il est allé

جلس

Sens : il s’est assis

فتح

Sens : il a ouvert

4Découper en syllabesNotion : déconstruction

Découpez chaque mot en syllabes : écrivez les syllabes séparées par un tiret.

نَزَلَ — il est descendu

شَرِبَ — il a bu

سَمِعَ — il a entendu

فَهِمَ — il a compris

عَمِلَ — il a travaillé

Lire

5Lire les mots de la séanceNotion : lecture

Lisez à voix haute, sans épeler.

كَتَبَدَرَسَذَهَبَجَلَسَفَتَحَنَزَلَشَرِبَسَمِعَفَهِمَعَمِلَ

6Lire des phrasesNotion : lecture

Lisez chaque phrase à voix haute, puis donnez-en le sens.

  1. كَتَبَ الطَّالِبُ الدَّرْسَ
  2. فَتَحَ الْحَارِسُ الْبَابَ
  3. ذَهَبَ الْمُعَلِّمُ إِلَى الْمَدْرَسَةِ
  4. جَلَسَ الْوَلَدُ عَلَى الْكُرْسِيِّ
  5. فَهِمَ الطَّالِبُ الدَّرْسَ

Dicter et écrire

7Dictée de motsNotion : dictée

Votre enseignant dicte 5 mots. Écrivez-les, avec leurs voyelles.

8Dictée de phrasesNotion : dictée

Votre enseignant dicte 2 phrases. Écrivez-les, avec leurs voyelles.

Corrigé (enseignant)
  • Exercice 1 : كَتَبَ الطَّالِبُ الدَّرْسَ (l’étudiant a écrit la leçon) ; فَتَحَ الْحَارِسُ الْبَابَ (le gardien a ouvert la porte) ; ذَهَبَ الْمُعَلِّمُ إِلَى الْمَدْرَسَةِ (l’enseignant est allé à l’école)
  • Exercice 2 : جَلَسَ / الْوَلَدُ / عَلَى / الْكُرْسِيِّ ; فَهِمَ / الطَّالِبُ / الدَّرْسَ
  • Exercice 3 : ك ت ب → كَتَبَ ; د ر س → دَرَسَ ; ذ ه ب → ذَهَبَ ; ج ل س → جَلَسَ ; ف ت ح → فَتَحَ
  • Exercice 4 : نَزَلَ → نَ – زَ – لَ (3) ; شَرِبَ → شَ – رِ – بَ (3) ; سَمِعَ → سَ – مِ – عَ (3) ; فَهِمَ → فَ – هِ – مَ (3) ; عَمِلَ → عَ – مِ – لَ (3)
  • Exercice 5 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 6 : traductions : 1. l’étudiant a écrit la leçon ; 2. le gardien a ouvert la porte ; 3. l’enseignant est allé à l’école ; 4. le garçon s’est assis sur la chaise ; 5. l’étudiant a compris la leçon
  • Exercice 7 : كَتَبَ ; دَرَسَ ; ذَهَبَ ; فَتَحَ ; شَرِبَ
  • Exercice 8 : كَتَبَ الطَّالِبُ الدَّرْسَ ; فَتَحَ الْحَارِسُ الْبَابَ
  • Exercice 9 : كَتَبَ = il a écrit ; دَرَسَ = il a étudié ; ذَهَبَ = il est allé ; جَلَسَ = il s’est assis ; فَتَحَ = il a ouvert ; نَزَلَ = il est descendu ; شَرِبَ = il a bu ; سَمِعَ = il a entendu ; فَهِمَ = il a compris ; عَمِلَ = il a travaillé
  • Exercice 10 : il a écrit = كَتَبَ ; il a étudié = دَرَسَ ; il est allé = ذَهَبَ ; il s’est assis = جَلَسَ ; il a ouvert = فَتَحَ ; il a bu = شَرِبَ
