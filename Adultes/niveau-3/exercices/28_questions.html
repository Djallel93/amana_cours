Exercices niveau 3 — Cours 28 : Poser une question et répondre

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Pour une classe rapide, deux pages peuvent être traitées dans la même séance.

Nom et prénom :   Date :

Construire et déconstruire

1Construire des motsNotion : construction

Assemblez les lettres pour écrire chaque mot, avec ses voyelles.

هل

Sens : est-ce que

ما

Sens : quoi

أين

Sens : où

كم

Sens : combien

2Déconstruire des motsNotion : déconstruction

Séparez le mot en lettres : écrivez chaque lettre isolément, de droite à gauche.

مَنْ — qui

كَيْفَ — comment

لِمَاذَا — pourquoi

نَعَمْ — oui

Lire

3Lire les mots de la séanceNotion : lecture

Lisez à voix haute, sans épeler.

هَلْمَامَنْأَيْنَكَيْفَكَمْلِمَاذَانَعَمْسُوقٌثَمَنٌ

4Lire des phrasesNotion : lecture

Lisez chaque phrase à voix haute, puis donnez-en le sens.

  1. هَلْ هَٰذَا كِتَابٌ؟
  2. نَعَمْ ، هَٰذَا كِتَابٌ
  3. أَيْنَ الْمِفْتَاحُ؟
  4. الْمِفْتَاحُ عَلَى الطَّاوِلَةِ
  5. هَلِ الْكِتَابُ جَدِيدٌ؟
  6. مَنْ هَٰذَا؟

Dicter et écrire

5Dictée de motsNotion : dictée

Votre enseignant dicte 5 mots. Écrivez-les, avec leurs voyelles.

6Dictée de phrasesNotion : dictée

Votre enseignant dicte 2 phrases. Écrivez-les, avec leurs voyelles.

Corrigé (enseignant)
  • Exercice 1 : ه ل → هَلْ ; م ا → مَا ; أ ي ن → أَيْنَ ; ك م → كَمْ
  • Exercice 2 : مَنْ → م - ن ; كَيْفَ → ك - ي - ف ; لِمَاذَا → ل - م - ا - ذ - ا ; نَعَمْ → ن - ع - م
  • Exercice 3 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 4 : traductions : 1. est-ce un livre ? ; 2. oui, c’est un livre ; 3. où est la clé ? ; 4. la clé est sur la table ; 5. le livre est-il neuf ? ; 6. qui est-ce ?
  • Exercice 5 : هَلْ ; مَا ; مَنْ ; أَيْنَ ; لِمَاذَا
  • Exercice 6 : هَلْ هَٰذَا كِتَابٌ؟ ; نَعَمْ ، هَٰذَا كِتَابٌ
  • Exercice 7 : أَيْنَ الْمِفْتَاحُ؟ = où est la clé ? ; مَا هَٰذَا؟ = qu’est-ce que c’est ? ; مَنْ هَٰذَا؟ = qui est-ce ?
  • Exercice 8 : هَلْ = est-ce que ; مَا = quoi ; مَنْ = qui ; أَيْنَ = où ; كَيْفَ = comment ; كَمْ = combien ; لِمَاذَا = pourquoi ; نَعَمْ = oui ; سُوقٌ = marché ; ثَمَنٌ = prix
  • Exercice 9 : est-ce que = هَلْ ; quoi = مَا ; qui = مَنْ ; où = أَيْنَ ; pourquoi = لِمَاذَا ; oui = نَعَمْ
