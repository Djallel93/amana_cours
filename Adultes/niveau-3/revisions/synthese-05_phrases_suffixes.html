Révision de rentrée R5 — Suffixes, phrases et rencontre de deux سُكُونٌ

مُرَاجَعَةٌ

Cette révision regroupe les pronoms suffixes, la هَمْزَةٌ devant un suffixe, la phrase nominale, les mots de lieu, la phrase verbale, les questions et la rencontre de deux سُكُونٌ.

Objectifs

  • Ajouter un pronom suffixe à un nom
  • Lire et écrire une phrase nominale et une phrase verbale
  • Situer un objet avec un mot de lieu
  • Lire un groupe où deux سُكُونٌ se rencontrent

Cours révisés

  • Cours 22 : Quand deux سُكُونٌ se rencontrent (1) : voyelle longue et مِنَ الْ
  • Cours 23 : Les pronoms suffixes : mon, ton, son…
  • Cours 24 : La هَمْزَةٌ avec les pronoms suffixes et dans les pluriels
  • Cours 25 : La phrase nominale : le meuble est…
  • Cours 26 : Où est-ce ? Les mots de lieu
  • Cours 27 : La phrase verbale : le verbe au passé
  • Cours 28 : Poser une question et répondre
  • Cours 29 : Quand deux سُكُونٌ se rencontrent (2) : la كَسْرَةٌ, le مِيمٌ du pluriel et قُلْتُ

Déroulement conseillé

  • Faites l’auto-test sans regarder la synthèse.
  • Relisez la synthèse en lisant les mots à voix haute.
  • Faites les exercices dans l’ordre.

1 · Avant de relire : où en êtes-vous ?

Répondez sans regarder la synthèse.

  1. Écris « mon livre » en arabe. →
  2. Que veut dire الطَّاوِلَةُ كَبِيرَةٌ ? →
  3. Que veut dire فَوْقَ ? →
  4. Que veut dire أَيْنَ ? →
  5. Quelle voyelle ajoute-t-on à مِنْ devant l’article (مِنَ الْبَيْتِ) ? →
  6. Que veut dire قُلْتُ ? →

2 · Synthèse

Un pronom suffixe se colle à la fin du nom : le تَنْوِينٌ disparaît et ة devient ت.

SuffixeSensAvec كِتَابٌAvec حَقِيبَةٌ
ـِيmon, maكِتَابِيحَقِيبَتِي
ـكَton, ta (homme)كِتَابُكَحَقِيبَتُكَ
ـكِton, ta (femme)كِتَابُكِحَقِيبَتُكِ
ـهُson, sa (lui)كِتَابُهُحَقِيبَتُهُ
ـهَاson, sa (elle)كِتَابُهَاحَقِيبَتُهَا
ـنَاnotre, nosكِتَابُنَاحَقِيبَتُنَا

Phrase nominale : الطَّاوِلَةُ كَبِيرَةٌ. Phrase verbale : كَتَبَ الطَّالِبُ الدَّرْسَ. Mot de lieu : الْقَلَمُ تَحْتَ الْكِتَابِ. Question : أَيْنَ الْمِفْتَاحُ؟

Premier motVoyelle ajoutéeExemple
هَلْ, قَالَتْkasraهَلِ الْكِتَابُ جَدِيدٌ؟
مِنْfathaمِنَ الْبَيْتِ
كُمْ, هُمْdammaعَلَيْكُمُ السَّلَامُ

3 · Exercices

1Les pronoms suffixesNotion : suffixes

Ajoutez le suffixe. Le تَنْوِينٌ disparaît et ة devient ت.

  1. كِتَابٌ + son (à lui) →
  2. حَقِيبَةٌ + mon →
  3. كِتَابٌ + ton (à une femme) →
  4. حَقِيبَةٌ + notre →
  5. حَقِيبَةٌ + son (à elle) →
  6. كِتَابٌ + ton (à un homme) →

2La hamza devant un suffixeNotion : hamza et suffixes

Écrivez le mot : la voyelle de la هَمْزَةٌ choisit le support.

  1. أَبْنَاءٌ + ـكَ (damma) →
  2. أَبْنَاءٌ + ـكَ (kasra) →
  3. أَبْنَاءٌ + ـكَ (fatha) →
  4. دُعَاءٌ + ـهُ (damma) →
  5. دُعَاءٌ + ـهِ (kasra) →
  6. دُعَاءٌ + ـهُ (fatha) →

3La phrase nominaleNotion : phrase nominale

Traduisez la phrase. L’arabe n’a pas de verbe « être » ici.

  1. الْمِصْبَاحُ جَدِيدٌ →
  2. الطَّاوِلَةُ كَبِيرَةٌ →
  3. الْخِزَانَةُ قَدِيمَةٌ →
  4. التِّلْفَازُ صَغِيرٌ →

4Où est-ce ?Notion : lieu

Traduisez. Après un mot de lieu, le nom prend une كَسْرَةٌ finale.

  1. الْمِصْبَاحُ فَوْقَ الْمَكْتَبِ →
  2. الْقَلَمُ تَحْتَ الْكِتَابِ →
  3. الْكُرْسِيُّ أَمَامَ الْمَكْتَبِ →
  4. الْبَابُ خَلْفَ الْكُرْسِيِّ →
  5. الطَّاوِلَةُ بَيْنَ الْبَابِ وَالنَّافِذَةِ →

5Remettre dans l’ordreNotion : phrase verbale

Écrivez la phrase : verbe, sujet, complément.

  1. الطَّالِبُ / الدَّرْسَ / كَتَبَ →
  2. الْبَابَ / فَتَحَ / الْحَارِسُ →
  3. الْمُعَلِّمُ / ذَهَبَ →
  4. الْوَلَدُ / جَلَسَ / عَلَى الْكُرْسِيِّ →

6Les mots interrogatifsNotion : questions

Écrivez le sens du mot.

  1. هَلْ →
  2. مَا →
  3. مَنْ →
  4. أَيْنَ →
  5. كَيْفَ →

4 · Textes d’entraînement

Texte 1 — Ma chambre غُرْفَتِي

Description Un petit texte pour revoir le suffixe, la phrase nominale, les mots de lieu et la question.

هَٰذِهِ غُرْفَتِي. الطَّاوِلَةُ كَبِيرَةٌ وَالْمِصْبَاحُ جَدِيدٌ. الْكِتَابُ عَلَى الطَّاوِلَةِ وَالْقَلَمُ تَحْتَ الْكِتَابِ. أَيْنَ الْمِفْتَاحُ؟ الْمِفْتَاحُ فَوْقَ الْخِزَانَةِ.

Questions أَسْئِلَةٌ

Lisez le texte à voix haute, puis répondez.

  1. Comment est la table ?
  2. Où est le stylo ?
  3. Où est la clé ?
  4. Écris le mot qui veut dire « ma chambre ».
📚 À retenir :
  • Après un mot de lieu, le nom prend une كَسْرَةٌ finale.
  • Dans une phrase verbale : verbe, sujet, complément.
  • Deux سُكُونٌ de suite : on ajoute une voyelle brève (كَسْرَةٌ en général, فَتْحَةٌ pour مِنْ).
