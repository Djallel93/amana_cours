Les types de phrases en arabe

الجُمْلة العَرَبِيَّة
Maintenant que tu maîtrises la conjugaison des verbes à trois lettres (passé, présent/futur, impératif), il est temps de comprendre comment assembler des phrases complètes en arabe. L'arabe distingue deux grands types de phrases : la phrase nominale (الجُمْلة الاِسْمِيَّة) et la phrase verbale (الجُمْلة الفِعْلِيَّة). Chacune a sa propre structure — et toutes deux sont indispensables pour communiquer au quotidien.

📊 Vue d'ensemble

Phrase nominale

الجُمْلة الاِسْمِيَّة

Commence par un nom ou un pronom

Pas de verbe obligatoire

Équivalent de "A est B" en français

Sujet + Information

Phrase verbale

الجُمْلة الفِعْلِيَّة

Commence par un verbe

Le verbe est obligatoire

Équivalent de "X fait Y" en français

Verbe + Sujet (+ Complément)
💡 À retenir : L'ordre des mots est l'indice clé ! Si la phrase commence par un nom ou un pronom ← c'est une phrase nominale. Si elle commence par un verbe → c'est une phrase verbale.
🏠 Partie 1

🏷️ La phrase nominale — الجُمْلة الاِسْمِيَّة

La phrase nominale est construite sans verbe. Elle exprime une identité, une description ou un état. En français on utilise toujours le verbe « être », mais en arabe il n'est pas nécessaire au présent !

Elle est composée de deux éléments :
  • المُبْتَدَأ — le sujet : ce dont on parle (toujours au cas sujet ضمة)
  • الخَبَر — l'information : ce qu'on dit du sujet (aussi au cas sujet ضمة)
⚙️ Formule :

المُبْتَدَأ (sujet) + الخَبَر (information)

Les deux sont au cas sujet (مَرْفُوع ← ضَمَّة)

🔬 Anatomie d'une phrase nominale

كَبِيرٌ
Information (خَبَر)
←
البَيْتُ
Sujet (مُبْتَدَأ)
البَيْتُ كَبِيرٌ → La maison (est) grande
Sujet (مُبْتَدَأ)
Information (خَبَر)

📝 Exemples détaillés

السَّيَّارَةُ سَرِيعَةٌ
La voiture (est) rapide
Sujet : السَّيَّارَةُ (la voiture, cas sujet) — Information : سَرِيعَةٌ (rapide, cas sujet)
الطَّالِبُ مُجْتَهِدٌ
L'étudiant (est) appliqué
Sujet : الطَّالِبُ — Information : مُجْتَهِدٌ
المَدِينَةُ جَمِيلَةٌ
La ville (est) belle
Sujet : المَدِينَةُ — Information : جَمِيلَةٌ
هُوَ طَالِبٌ
Il (est) étudiant
Sujet : هُوَ (pronom, indéclinable) — Information : طَالِبٌ
هَذا كِتَابٌ
Ceci (est) un livre
Sujet : هَذا (démonstratif, indéclinable) — Information : كِتَابٌ

📚 L'information (الخَبَر) peut être de plusieurs formes

Type d'information Exemple arabe Traduction
Adjectif الجَوُّ بَارِدٌ Le temps (est) froid
Nom مُحَمَّدٌ طَبِيبٌ Mohamed (est) médecin
Adverbe de lieu الكِتَابُ هُنَا Le livre (est) ici
Groupe prépositionnel الوَلَدُ فِي البَيْتِ Le garçon (est) à la maison
📌 Rappel sur l'accord : Le sujet et l'information doivent s'accorder en genre (masculin/féminin) et en nombre (singulier, duel, pluriel).
✅ الوَلَدُ صَغِيرٌ (Le garçon est petit — masculin/masculin)
✅ البِنْتُ صَغِيرَةٌ (La fille est petite — féminin/féminin)
⚡ Partie 2

🔤 La phrase verbale — الجُمْلة الفِعْلِيَّة

La phrase verbale commence toujours par un verbe. C'est la structure naturelle pour exprimer des actions. Elle obéit à l'ordre Verbe → Sujet → Complément, ce qui est l'inverse du français (Sujet → Verbe → Complément).
⚙️ Formule :

فِعْل (verbe) + فَاعِل (sujet) + مَفْعُول (complément)

Le verbe en tête — le sujet au cas sujet — le complément direct au cas direct

⚖️ Les cas grammaticaux dans la phrase verbale

Élément Nom arabe Cas Voyelle finale
Verbe الفِعْل — Conjugué normalement
Sujet الفَاعِل Cas sujet (مَرْفُوع) ضَمَّة ( ُ )
Complément direct المَفْعُول بِهِ Cas direct (مَنْصُوب) فَتْحَة ( َ )

🔬 Anatomie d'une phrase verbale

رِسَالَةً

←
الوَلَدُ

←
كَتَبَ

Verbe (فِعْل)
Sujet verbal (فَاعِل)
Complément (مَفْعُول)

📝 Exemples au passé (الماضي)

ذَهَبَ الطَّالِبُ إِلَى المَدْرَسَةِ
L'étudiant est allé à l'école
Verbe : ذَهَبَ (il est allé) — Sujet : الطَّالِبُ — Complément : إِلَى المَدْرَسَةِ
أَكَلَتْ البِنْتُ تُفَّاحَةً
La fille a mangé une pomme
Verbe : أَكَلَتْ (elle a mangé, féminin) — Sujet : البِنْتُ — Complément : تُفَّاحَةً
فَتَحَ الأُسْتَاذُ الكِتَابَ
Le professeur a ouvert le livre
Verbe : فَتَحَ — Sujet : الأُسْتَاذُ — Complément : الكِتَابَ (défini → فتحة)

📝 Exemples au présent (المُضارِع)

يَشْرَبُ الوَلَدُ مَاءً
Le garçon boit de l'eau
Verbe : يَشْرَبُ (il boit) — Sujet : الوَلَدُ — Complément : مَاءً
تَدْرُسُ الطَّالِبَةُ العَرَبِيَّةَ
L'étudiante étudie l'arabe
Verbe : تَدْرُسُ (elle étudie) — Sujet : الطَّالِبَةُ — Complément : العَرَبِيَّةَ
⚠️ Règle importante : Quand le sujet est explicitement mentionné après le verbe dans une phrase verbale, le verbe reste toujours au singulier, même si le sujet est au pluriel !

✅ يَعْمَلُ الرِّجَالُ → Les hommes travaillent (verbe au singulier 3ème masc.)
✅ تَضْحَكُ النِّسَاءُ → Les femmes rient (verbe au singulier 3ème fém.)

🔗 Lien avec la conjugaison

🔗 Connexion avec la conjugaison apprise

Tu connais déjà la conjugaison. Voyons comment tes verbes s'intègrent dans les deux types de phrases.
Le verbe كَتَبَ / يَكْتُبُ (écrire) dans les deux structures :
  • Phrase verbale (action) :
    يَكْتُبُ الأُسْتَاذُ الدَّرْسَ → Le professeur écrit la leçon
  • Phrase nominale (description, sans verbe) :
    الأُسْتَاذُ مَاهِرٌ → Le professeur est habile
Avec l'impératif (الأَمْر) — toujours une phrase verbale courte :
  • اُكْتُبْ الدَّرْسَ → Écris la leçon ! (le sujet « tu » est implicite dans le verbe)
  • اِفْهَمُوا السُّؤالَ → Comprenez la question !
💡 Le sujet implicite : Dans une phrase verbale, le sujet n'a pas toujours besoin d'être mentionné. La conjugaison du verbe l'indique déjà !
كَتَبْتُ رِسَالَةً → J'ai écrit une lettre (le « je » est intégré dans كَتَبْتُ)

🤔 Nominale ou verbale — comment choisir ?

Pose-toi une seule question : « Est-ce que je décris quelque chose, ou est-ce que je raconte une action ? »
📸

Phrase nominale = une photo

Elle capture un état, une description, une identité.

Pas de mouvement, pas d'action.

Verbe « être » en français
🎬

Phrase verbale = une vidéo

Elle raconte quelque chose qui se passe, qui s'est passé, qui va se passer.

Il y a du mouvement.

Tout autre verbe en français

🧪 Le test pratique

Traduis ta phrase en français et trouve le verbe principal :
  • Le verbe principal est « être » → phrase nominale (et on supprime le « est » en arabe !)
  • Le verbe principal est n'importe quel autre verbe → phrase verbale

📝 Exemples comparés

Phrase française Verbe principal Type En arabe
Le ciel est bleu être → description 📸 Nominale السَّمَاءُ زَرْقَاءُ
Ahmed est médecin être → identité 📸 Nominale أَحْمَدُ طَبِيبٌ
Ahmed mange une pomme manger → action 🎬 Verbale يَأْكُلُ أَحْمَدُ تُفَّاحَةً
L'étudiant est allé à l'école aller → mouvement 🎬 Verbale ذَهَبَ الطَّالِبُ إِلَى المَدْرَسَةِ
Le livre est sur la table être → localisation 📸 Nominale الكِتَابُ عَلَى الطَّاوِلَةِ

⚠️ Le cas piège : « est » vs « est allé »

« être » de localisation ≠ « être » de mouvement

En français on utilise « être » dans les deux cas, mais en arabe la distinction est claire :
  • « il est à Paris » → état, localisation → 📸 nominale
    هُوَ فِي بَارِيسَ
  • « il est allé à Paris » → mouvement passé → 🎬 verbale
    ذَهَبَ إِلَى بَارِيسَ
Le truc : « est à » = état = nominale  /  « est allé » = mouvement = verbale.

📝 Résumé de la leçon

  • Il existe deux types de phrases en arabe : nominale (اِسْمِيَّة) et verbale (فِعْلِيَّة)
  • La phrase nominale = Sujet + Information, sans verbe obligatoire
  • La phrase verbale = Verbe + Sujet (+ Complément), le verbe est en tête
  • Dans les deux types, le sujet est toujours au cas sujet (ضَمَّة)
  • Dans la phrase verbale, le complément direct est au cas direct (فَتْحَة)
  • Dans une phrase verbale, si le sujet est mentionné explicitement, le verbe reste au singulier
  • Le sujet peut être implicite — la conjugaison du verbe suffit à l'indiquer
