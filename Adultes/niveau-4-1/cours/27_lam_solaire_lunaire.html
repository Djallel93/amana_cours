Le lām solaire et lunaire

اللَّامُ الشَّمْسِيَّةُ وَالقَمَرِيَّةُ
Dans la leçon 1, tu as appris que l'article défini est ال. Mais il ne se prononce pas toujours de la même façon ! Selon la première lettre du mot, le ل (lām) de l'article est soit prononcé (lettre lunaire), soit absorbé par la lettre suivante (lettre solaire). À l'écrit, le lām est toujours écrit : seule la prononciation change.

🌙☀️ Le principe

Les 28 lettres de l'alphabet se partagent en deux groupes de 14, nommés d'après deux mots :

  • القَمَرُ (al-qamar, « la lune ») : le lām se lit → lettres lunaires (الحُرُوفُ القَمَرِيَّةُ)
  • الشَّمْسُ (ash-shams, « le soleil ») : le lām ne se lit pas → lettres solaires (الحُرُوفُ الشَّمْسِيَّةُ)

🔄 Transformation : indéfini → défini

Les étapes de la leçon 1 restent valables (ajouter ال, supprimer le tanwīn), avec une étape en plus :

  1. Ajouter ال
  2. Supprimer le tanwīn
  3. Lettre lunaire → sukūn sur le lām الْ
  4. Lettre solaire → chadda sur la 1ʳᵉ lettre

🔗 Liaison entre les mots

La hamza de ال est une hamzat al-waṣl (voir la leçon 24) : elle disparaît quand le mot précédent est lié. Dans la phrase, on entend donc seulement le lām (lunaire) ou la lettre doublée (solaire).

🗣️ En phrases :

  • ذَهَبَ الوَلَدُ إِلَى المَدْرَسَةِ → dhahaba l-waladu ʾilā l-madrasati (lunaires)
  • قَرَأَ الطَّالِبُ الدَّرْسَ → qaraʾa ṭ-ṭālibu d-darsa (solaires)
  • الشَّمْسُ فِي السَّمَاءِ → ash-shamsu fī s-samāʾi

🔤 Avec les prépositions et la conjonction

MotÉcriturePrononciation

وَ + الْقَمَرُوَالْقَمَرُwa-l-qamaru (« et la lune »)
⚠️ Cas de لِـ : avec la préposition لِـ, l'alif de ال n'est pas écrit : لِلْبَيْتِ (et non لِالْبَيْتِ).
➡️ Et si le mot précédent se termine par un sukūn (مِنْ, عَنْ, هَلْ, لَمْ يَكْتُبْ…) ? Deux sukūn se rencontrent : on ajoute une voyelle (مِنَ الْبَيْتِ, مِنَ الشَّمْسِ). C'est l'objet de la leçon 28.

🌟 Cas à connaître

  • Le lām est solaire : اللَّيْلُ se prononce al-layl avec un l long ; اللُّغَةُ (al-lugha, « la langue »).
  • Noms composés : عَبْدُ الرَّحْمَنِ (ʿabd ar-raḥmān), نُورُ الدِّينِ (nūr ad-dīn), صَلَاحُ الدِّينِ (ṣalāḥ ad-dīn), عَبْدُ السَّلَامِ (ʿabd as-salām) sont solaires ; عَبْدُ الكَرِيمِ (ʿabd al-karīm) est lunaire.
  • Sans voyelles : dans un texte non vocalisé, il n'y a ni chadda ni sukūn pour t'aider : il faut connaître les deux listes.
📚 Résumé de la leçon :
  • 14 lettres lunaires 🌙 : ا ب ج ح خ ع غ ف ق ك م ه و ي → le lām se prononce
  • 14 lettres solaires ☀️ : ت ث د ذ ر ز س ش ص ض ط ظ ل ن → le lām est assimilé, la 1ʳᵉ lettre est doublée (chadda)
  • Le lām s'écrit toujours ; seule la prononciation change
  • La hamza de ال disparaît dans la liaison
