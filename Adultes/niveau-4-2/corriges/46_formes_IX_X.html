Corrigé — Cours 46 : Les formes IX et X

الْحَلُّ

1. Formes

  1. IX · ح م ر
  2. X · خ ر ج
  3. IX · ص ف ر
  4. X · ق ب ل
  5. X · ع م ل
  6. IX · خ ض ر

2. Passé de اِسْتَعْمَلَ

  1. اِسْتَعْمَلَتْ
  2. اِسْتَعْمَلُوا
  3. اِسْتَعْمَلْنَ
  4. اِسْتَعْمَلْتِ
  5. اِسْتَعْمَلْتُ
  6. اِسْتَعْمَلْنَا

3. Présent de اِسْتَقْبَلَ

  1. تَسْتَقْبِلُ
  2. يَسْتَقْبِلُونَ
  3. يَسْتَقْبِلْنَ
  4. تَسْتَقْبِلِينَ
  5. أَسْتَقْبِلُ
  6. نَسْتَقْبِلُ

4. Impératif de اِسْتَخْدَمَ

  1. اِسْتَخْدِمْ
  2. اِسْتَخْدِمِي
  3. اِسْتَخْدِمُوا
  4. اِسْتَخْدِمْنَ

5. Forme IX

  1. اِحْمَرَّ · اِحْمِرَارٌ
  2. اِصْفَرَّ · اِصْفِرَارٌ
  3. اِخْضَرَّ · اِخْضِرَارٌ
  4. اِسْوَدَّ · اِسْوِدَادٌ

6. Forme X

  1. اِسْتَغْفَرَ (demander pardon)
  2. اِسْتَخْرَجَ (extraire)
  3. اِسْتَعْمَلَ (utiliser)
  4. اِسْتَقْبَلَ (accueillir)

7. Maṣdar et participes

  1. اِسْتِخْدَامٌ · مُسْتَخْدِمٌ · مُسْتَخْدَمٌ
  2. اِسْتِعْمَالٌ · مُسْتَعْمِلٌ · مُسْتَعْمَلٌ
  3. اِسْتِقْبَالٌ · مُسْتَقْبِلٌ · مُسْتَقْبَلٌ

8. Forme IX

  1. اِصْفَرَّتْ
  2. اِصْفَرُّوا
  3. اِصْفَرَرْتُ
  4. يَصْفَرِرْنَ
  5. لَمْ يَصْفَرَّ

9. Traductions

  1. اِسْتَعْمَلْنَا الْقَامُوسَ.
  2. يَسْتَقْبِلُ الْمُدِيرُ الضُّيُوفَ.
  3. اِصْفَرَّتِ الْأَوْرَاقُ.
  4. اِسْتَخْدِمِ الْحَاسُوبَ.

10. Compréhension

  1. L'enseignante a accueilli les étudiants en classe. Elle a utilisé le nouveau livre. Le visage de l'étudiant est devenu rouge parce qu'il avait oublié sa leçon.
  2. اِسْتَقْبَلَ : X, ق ب ل, اِسْتِقْبَالٌ · اِسْتَخْدَمَ : X, خ د م, اِسْتِخْدَامٌ
  3. أَحْمَرُ
