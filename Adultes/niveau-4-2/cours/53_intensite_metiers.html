Cours 53 — Les schèmes d'intensité et les noms de métiers

صِيَغُ الْمُبَالَغَةِ وَأَسْمَاءُ الْمِهَنِ

Une même racine peut décrire une action ponctuelle (كَاذِبٌ, « menteur ») ou une action habituelle, intense, professionnelle (كَذَّابٌ, « grand menteur »). Ce sont les schèmes d'intensité (صِيَغُ الْمُبَالَغَةِ). Le plus productif, فَعَّالٌ, est aussi celui qui donne en arabe de très nombreux noms de métiers : on est ce que l'on fait tous les jours. [1] [2] [3] [4]

Objectifs

  • Reconnaître les schèmes d'intensité (فَعَّالٌ, فَعُولٌ, فَعِيلٌ, مِفْعَالٌ)
  • Former les noms de métiers sur فَعَّالٌ et sur le participe actif
  • Lire les noms d'objets et d'appareils en فَعَّالَةٌ

Prérequis

  • Cours 49 : les noms d'instrument
  • Cours 52 : les schèmes d'adjectifs

Nouveaux concepts

  • فَعَّالٌ · فَعُولٌ · فَعِيلٌ
  • نَجَّارٌ · خَبَّازٌ · بَقَّالٌ
  • غَسَّالَةٌ · ثَلَّاجَةٌ

1️⃣ Les schèmes d'intensité

SchèmeIdéeExemples
فَعَّالٌcelui qui fait souvent ou beaucoupكَذَّابٌ (grand menteur) · غَفَّارٌ (qui pardonne toujours) · وَهَّابٌ (très généreux)
فَعُولٌcelui qui est constamment ainsiغَفُورٌ (très clément) · شَكُورٌ (très reconnaissant) · صَبُورٌ (très patient) · ظَلُومٌ (très injuste)
فَعِيلٌqualité profonde, souvent d'un participeرَحِيمٌ (miséricordieux) · عَلِيمٌ (très savant) · سَمِيعٌ (qui entend tout) · بَصِيرٌ (qui voit tout) · قَدِيرٌ (tout-puissant)
مِفْعَالٌcelui qui fait avec insistanceمِعْطَاءٌ (très généreux) · مِهْذَارٌ (bavard)
🧠 Dans les textes. Plusieurs de ces schèmes servent aux noms et attributs divins (الْغَفُورُ الرَّحِيمُ, الْوَهَّابُ, الْغَفَّارُ) : les reconnaître aide à comprendre le sens de ces noms sans les apprendre par cœur. Ils servent aussi aux adjectifs du langage courant (صَبُورٌ, كَسُولٌ).

2️⃣ Les noms de métiers

Règle

Pour dire « celui qui exerce un métier », l'arabe emploie souvent فَعَّالٌ (la shadda indique la répétition quotidienne du geste), et le participe actif pour les métiers savants (مُفَعِّلٌ, فَاعِلٌ). Le féminin ajoute ـَةٌ : خَيَّاطٌ → خَيَّاطَةٌ. Le pluriel est généralement sain (ـُونَ) pour le masculin, (ـَاتٌ) pour le féminin.

Information

Le lien métier / lieu de travail est régulier : le نَجَّارٌ exerce la نِجَارَةٌ (la menuiserie) ; le خَبَّازٌ dans le مَخْبَزٌ (boulangerie) ; le طَبَّاخٌ dans le مَطْبَخٌ ; le بَقَّالٌ dans son دُكَّانٌ (boutique). Les noms d'activité en فِعَالَةٌ (تِجَارَةٌ, نِجَارَةٌ, خِيَاطَةٌ) désignent le métier lui-même (« le commerce », « la menuiserie », « la couture »).

3️⃣ Les noms d'appareils en فَعَّالَةٌ

Le féminin de فَعَّالٌ désigne aussi des objets et des appareils qui font le travail à la place de l'homme : c'est un nom d'instrument moderne :

MotRacineFrançais
غَسَّالَةٌغ س لmachine à laver
ثَلَّاجَةٌث ل جréfrigérateur
سَيَّارَةٌس ي رvoiture
طَيَّارَةٌط ي رavion (usage courant)
دَرَّاجَةٌد ر جvélo
نَظَّارَةٌن ظ رlunettes
عَدَّادٌع د دcompteur

Exemple

🌟 Dans des phrases

أَبِي نَجَّارٌ. — Mon père est menuisier.

اِشْتَرَيْتُ الْخُبْزَ مِنَ الْخَبَّازِ. — J'ai acheté le pain chez le boulanger.

أُخْتِي مُمَرِّضَةٌ فِي الْمُسْتَشْفَى. — Ma sœur est infirmière à l'hôpital.

اللّٰهُ غَفُورٌ رَحِيمٌ. — Dieu est clément et miséricordieux.

رَكِبْنَا السَّيَّارَةَ. — Nous sommes montés dans la voiture.

📚 Résumé de la leçon :
  • Intensité : فَعَّالٌ, فَعُولٌ, فَعِيلٌ, مِفْعَالٌ
  • Métiers : فَعَّالٌ (نَجَّارٌ), participes (مُعَلِّمٌ, مُمَرِّضٌ), فَاعِلٌ (سَائِقٌ)
  • Féminin ـَةٌ : خَيَّاطَةٌ (la couturière) ; et فَعَّالَةٌ pour les appareils : ثَلَّاجَةٌ
