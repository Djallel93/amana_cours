Évaluation 3 — noms dérivés, pluriels, comparatif

Nom et prénom :   Date :

Évaluation notée sur 20 (les points sont indiqués à chaque exercice). Elle porte sur les cours 47 à 51 : maṣdar, noms de lieu et d'instrument, pluriels brisés, élatif, nisba, métiers.

1Noms de lieu et d'instrumentNotion : noms de lieu, d'instrument · 4 points

Écrivez la forme demandée, avec ses voyelles. (1 point par réponse juste)

  1. كَتَبَ : nom de lieu (bureau) →
  2. دَرَسَ : nom de lieu (école) →
  3. فَتَحَ : nom d'instrument (clé) →
  4. طَبَخَ : nom de lieu (cuisine) →

2Le nom d'unitéNotion : nom d'unité · 2 points

Écrivez la forme demandée, avec ses voyelles. (1 point par réponse juste)

  1. ضَرَبَ : un coup →
  2. جَلَسَ : une séance →

3Les pluriels brisésNotion : pluriels brisés · 4 points

Écrivez le pluriel brisé, avec ses voyelles. (1 point par réponse juste)

  1. كِتَابٌ →
  2. قَلَمٌ →
  3. رَجُلٌ →
  4. بَيْتٌ →

4Le comparatifNotion : élatif · 3 points

Écrivez l'élatif (« plus … »), avec ses voyelles. (1 point par réponse juste)

  1. كَبِيرٌ →
  2. صَغِيرٌ →
  3. جَمِيلٌ →

5Diptotes et élatifNotion : diptotes, élatif · 2 points

Cochez la bonne forme. (1 point par réponse juste)

  1. « avec Ahmed » مَعَ أَحْمَدَ مَعَ أَحْمَدِ
  2. « Il est plus grand que moi. » هُوَ أَكْبَرُ مِنِّي هُوَ أَكْبَرٌ مِنِّي

6La nisbaNotion : nisba · 3 points

  2. عَرَبٌ (arabe) →
  3. مَدْرَسَةٌ (scolaire) →

7Les métiersNotion : schèmes d'intensité, métiers · 2 points
