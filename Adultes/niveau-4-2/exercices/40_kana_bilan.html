3L'attribut

Mettez la phrase nominale avec كَانَ

  1. الْجَوُّ بَارِدٌ →
  2. الْبِنْتُ سَعِيدَةٌ →
  3. الْمُعَلِّمُونَ جَاهِزُونَ →
  4. الْبَيْتُ كَبِيرٌ →

4Négation

Mettez à la négation avec لَيْسَ

  1. أَنَا جَائِعٌ →
  2. الْمَدِينَةُ كَبِيرَةٌ →
  3. هُمْ مُتَأَخِّرُونَ →
  4. نَحْنُ مُتْعَبُونَ →

5Les sœurs de كَانَ

Complétez avec le verbe de la liste : أَصْبَحَ · ظَلَّ · بَاتَ · صَارَ · مَا زَالَ (attribut au bon cas)

  1. … الْمَاءُ بَارِدًا (devenir) →
  2. … الْبَابُ مَفْتُوحًا (rester) →
  3. … الطِّفْلُ نَائِمًا (il dort encore) →
  4. … الْجَوُّ حَارًّا (ce matin) →

7Conjuguer

Écrivez les formes demandées

  1. أَكَلَ, أَنَا, présent →
  2. مَدَّ, هُمْ, passé →
  3. وَصَلَ, impératif (أَنْتَ) →
  4. قَالَ, أَنَا, passé →
  5. دَعَا, هُمْ, apocopé →
  6. وَقَى, impératif (أَنْتَ) →

8Repérer l'erreur

Corrigez la forme fautive

  1. لَمْ يَدْعُو →
  2. لَمْ يَقُولْ →

  4. كَانَ الْجَوُّ جَمِيلٌ →

9Traduisez en arabe

Écrivez les phrases (avec les voyelles)

  2. Je ne suis pas fatigué →

10Compréhension

Lisez et répondez

{{كَانَ الْجَوُّ بَارِدًا، فَبَاتَ الْوَلَدُ فِي الْبَيْتِ. لَمْ يَكُنْ جَائِعًا، وَمَا زَالَ نَائِمًا حِينَ أَصْبَحَ الصَّبَاحُ.}}

Questions :

  1. Traduisez le texte en français.
  2. Donnez le type de بَاتَ et de كَانَ.
  3. Quel est le cas de بَارِدًا ? Pourquoi ?
  4. Mettez لَمْ يَكُنْ à la 1re personne du singulier.
💡 Conseil : après كَانَ et ses sœurs, vérifiez toujours le cas de l'attribut avant de relire.
Corrigé

1. كَانَ

  1. كَانَتْ · تَكُونُ · لَمْ تَكُنْ
  2. كَانُوا · يَكُونُونَ · لَمْ يَكُونُوا
  3. كُنْتِ · تَكُونِينَ · لَمْ تَكُونِي
  4. كُنْتُ · أَكُونُ · لَمْ أَكُنْ
  5. كُنَّا · نَكُونُ · لَمْ نَكُنْ

2. لَيْسَ

  1. لَيْسَتْ
  2. لَيْسُوا
  3. لَسْنَ
  4. لَسْتَ
  5. لَسْتُ
  6. لَسْنَا

3. Attribut

  1. كَانَ الْجَوُّ بَارِدًا
  2. كَانَتِ الْبِنْتُ سَعِيدَةً
  3. كَانَ الْمُعَلِّمُونَ جَاهِزِينَ
  4. كَانَ الْبَيْتُ كَبِيرًا

4. Négation

  1. لَسْتُ جَائِعًا
  2. لَيْسَتِ الْمَدِينَةُ كَبِيرَةً
  3. لَيْسُوا مُتَأَخِّرِينَ
  4. لَسْنَا مُتْعَبِينَ

5. Sœurs

  1. صَارَ
  2. ظَلَّ
  3. مَا زَالَ

6. Types

  1. ء ك ل · hamzé
  2. م د د · redoublé
  3. و ص ل · assimilé
  4. ق و ل · creux
  5. ر م ي · défectueux
  6. و ق ي · lafīf mafrūq
  7. ك ت ب · sain

7. Formes

  1. آكُلُ
  2. مَدُّوا
  3. صِلْ
  4. قُلْتُ
  5. لَمْ يَدْعُوا
  6. قِ

8. Erreurs

  1. لَمْ يَدْعُ (la voyelle longue tombe)
  2. لَمْ يَقُلْ (sukūn, pas de voyelle longue)
  3. وَصَلَ الطَّالِبُ مُتَأَخِّرًا (accusatif de manière)
  4. كَانَ الْجَوُّ جَمِيلًا (attribut accusatif)

9. Traductions

  1. كَانَ الْجَوُّ جَمِيلًا
  2. لَسْتُ مُتْعَبًا
  3. ظَلَّتْ سَاكِتَةً
  4. صَارَتِ السَّمَاءُ دَاكِنَةً
  5. مَا زَالُوا يَدْرُسُونَ

10. Compréhension

  1. Le temps était froid, alors le garçon est resté à la maison pour la nuit. Il n'avait pas faim et dormait encore quand le matin est venu.
  2. بَاتَ : creux ; كَانَ : creux
  3. Accusatif, car c'est l'attribut de كَانَ.
  4. لَمْ أَكُنْ
