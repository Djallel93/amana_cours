Exercices — Cours 47 : Le مَصْدَرٌ, le nom d'unité, les noms de lieu, de temps et d'instrument

تَمَارِين

👋 Instructions : ces exercices accompagnent le cours 47. Partez toujours de la racine, puis cherchez le schème.

1Nom d'unité

Écrivez le nom d'unité (فَعْلَةٌ) et traduisez

  1. نَظَرَ →
  2. ضَرَبَ →
  3. ضَحِكَ →
  4. خَطَا →

2Nom de manière

Écrivez le nom de manière (فِعْلَةٌ)

  1. جَلَسَ →
  2. مَشَى →
  3. عَاشَ →

3Lieu

Écrivez le nom de lieu à partir du verbe

  1. يَلْعَبُ →
  2. يَكْتُبُ →
  3. يَطْبُخُ →
  4. يَجْلِسُ →
  5. يَدْخُلُ →
  6. يَنْزِلُ →

4Assimilés

Écrivez le nom de lieu ou de temps

  1. وَعَدَ →
  2. وَقَفَ →
  3. وَضَعَ →

5Instruments

Donnez le sens du mot, puis sa racine

  1. مِفْتَاحٌ →
  2. مِكْنَسَةٌ →
  3. مِصْبَاحٌ →
  4. مِلْعَقَةٌ →
  5. مِسْطَرَةٌ →

6Pluriels

Écrivez le pluriel

  1. مَكْتَبٌ →
  2. مَدْرَسَةٌ →
  3. مَسْجِدٌ →
  4. مِفْتَاحٌ →
  5. مَوْعِدٌ →

7Complétez la phrase

Choisissez le mot : مَكْتَبَةٌ · مِفْتَاحٌ · مَوْعِدٌ · مَطْبَخٌ · مِكْنَسَةٌ

  1. أَنْظُرُ إِلَى الْكُتُبِ فِي الـ… →
  2. أَفْتَحُ الْبَابَ بِالـ… →
  3. أُحَضِّرُ الْعَشَاءَ فِي الـ… →
  4. نَظَّفْتُ الْغُرْفَةَ بِالـ… →
  5. نَسِيتُ الـ… →

8Traduisez en arabe

Écrivez les phrases (avec les voyelles)

  1. Le rendez-vous est demain →
  2. La clé est sur le bureau →
  3. Les étudiants sont à la bibliothèque →
  4. Il m'a lancé un regard →

9Compréhension

Lisez et répondez

ذَهَبْتُ إِلَى الْمَدْرَسَةِ. دَخَلْتُ مِنَ الْمَدْخَلِ وَجَلَسْتُ فِي الْمَكْتَبَةِ. وَجَدْتُ الْمِفْتَاحَ عَلَى الْمَكْتَبِ، فَفَتَحْتُ بِهِ الْبَابَ. كَانَ مَوْعِدُ الدَّرْسِ بَعْدَ سَاعَةٍ.

Questions :

  1. Traduisez le texte en français.
  2. Relevez les noms de lieu, de temps et d'instrument, et donnez leur racine.
💡 Conseil : quand un mot commence par مَـ et désigne un endroit, cherchez le verbe de forme I : le sens du lieu s'en déduit.
