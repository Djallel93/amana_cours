Exercices — Cours 50 : La nisba et l'adjectif attributif (ṣifa mushabbaha)

تَمَارِين

👋 Instructions : ces exercices accompagnent le cours 50. Pour une nisba, retirez la ـَةٌ finale avant d'ajouter ـِيٌّ.

1Former la nisba

Écrivez la nisba au masculin et au féminin

2Retrouver le nom

Écrivez le nom d'origine

  1. سُورِيٌّ →
  2. إِسْلَامِيٌّ →
  3. شَهْرِيٌّ →
  4. طَبِيعِيٌّ →

3Déclinaison

Mettez la nisba au cas indiqué (avec les voyelles)

  1. رَأَيْتُ مُعَلِّمًا … (مِصْرِيٌّ) →
  2. سَلَّمْتُ عَلَى الطَّالِبِ … (جَزَائِرِيٌّ) →
  3. هَذِهِ طَالِبَةٌ … (جَامِعِيٌّ) →
  4. الطُّلَّابُ … (فَرَنْسِيٌّ, pluriel) →

4Noms abstraits

Écrivez le nom abstrait en ـِيَّةٌ

  1. حُرٌّ →
  2. إِنْسَانٌ →
  3. مَسْؤُولٌ →
  4. أَهَمُّ →

6L'accord

Complétez avec l'adjectif entre parenthèses, accordé

  1. الْمُدُنُ … (كَبِيرٌ) →
  2. سَيَّارَةٌ … (أَحْمَرُ) →
  3. الْبِنْتُ … (جَوْعَانُ) →
  4. رَأَيْتُ سَيَّارَاتٍ … (أَخْضَرُ, pluriel non humain) →

7Traduisez en arabe

Écrivez les phrases (avec les voyelles)

  1. C'est un étudiant marocain →
  2. Elle est une enseignante algérienne →
  3. Je lis le journal mensuel →
  4. La liberté est une responsabilité →

8Compréhension

Lisez et répondez

هِيَ طَالِبَةٌ جَامِعِيَّةٌ مِنْ تُونِسَ. تَسْكُنُ فِي مَدِينَةٍ كَبِيرَةٍ، وَتَقْرَأُ الْجَرِيدَةَ الْيَوْمِيَّةَ. تُحِبُّ الْعُلُومَ الطَّبِيعِيَّةَ، وَتَرَى أَنَّ الْحُرِّيَّةَ مَسْؤُولِيَّةٌ.

Questions :

  1. Traduisez le texte en français.
  2. Relevez les nisba et donnez le nom dont elles dérivent.
  3. Relevez les noms abstraits en ـِيَّةٌ.
💡 Conseil : la nisba est une clé de lecture : quand un adjectif se termine par ـِيٌّ, cherchez le nom dont il dérive.
