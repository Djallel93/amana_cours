Exercices — Cours 51 : Les schèmes d'intensité et les noms de métiers

تَمَارِين

👋 Instructions : ces exercices accompagnent le cours 51. Partez de la racine, puis cherchez le schème de métier.

1Racines et sens

Donnez la racine et le sens

  1. نَجَّارٌ →
  2. خَبَّازٌ →
  3. بَقَّالٌ →
  4. حَلَّاقٌ →
  5. سَبَّاحٌ →
  6. فَلَّاحٌ →

2Former le métier

Écrivez le nom de métier sur فَعَّالٌ à partir de la racine

  1. خ ي ط →
  2. ط ب خ →
  3. ل ح م →
  4. ج ز ر (boucher) →
  5. ص ي د (chasseur) →

3Masculin et féminin

Écrivez le féminin

  1. طَبَّاخٌ →
  2. خَيَّاطٌ →
  3. مُعَلِّمٌ →
  4. مُمَرِّضٌ →
  5. سَائِقٌ →

4Appareils

Écrivez le mot arabe

  1. machine à laver →
  2. réfrigérateur →
  3. voiture →
  4. vélo →
  5. lunettes →

5Intensité

Donnez le sens de l'adjectif et son schème

  1. صَبُورٌ →
  2. رَحِيمٌ →
  3. كَذَّابٌ →
  4. غَفُورٌ →
  5. سَمِيعٌ →

6Qui travaille où ?

Associez le métier et le lieu : الْمَطْبَخُ · الْمَخْبَزُ · الْمُسْتَشْفَى · الْمَدْرَسَةُ · الْمَكْتَبُ

  1. الطَّبَّاخُ →
  2. الْخَبَّازُ →
  3. الطَّبِيبُ →
  4. الْمُعَلِّمُ →
  5. الْمُحَاسِبُ →

7Traduisez en arabe

Écrivez les phrases (avec les voyelles)

  1. Mon frère est médecin →
  2. Elle est couturière →
  3. Le boulanger est ici →
  4. J'ai acheté un réfrigérateur →

8Compréhension

Lisez et répondez

أَبِي خَبَّازٌ، وَأُمِّي خَيَّاطَةٌ. أَخِي سَائِقٌ، وَأُخْتِي مُمَرِّضَةٌ فِي الْمُسْتَشْفَى. جَدِّي نَجَّارٌ قَدِيمٌ وَهُوَ صَبُورٌ جِدًّا.

Questions :

  1. Traduisez le texte en français.
  2. Relevez les noms de métiers et donnez leur racine.
  3. Quel est le schème de صَبُورٌ et que signifie-t-il ?
💡 Conseil : lorsque vous rencontrez un mot en فَعَّالٌ, pensez d'abord à un métier, et à l'idée d'« habituel » ou d'« intense » si le contexte ne s'y prête pas.
