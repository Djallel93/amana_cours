Exercices — Cours 53 : Les pluriels brisés : les grands schèmes

تَمَارِين

👋 Instructions : ces exercices accompagnent le cours 53. Si vous hésitez, demandez-vous d'abord combien de lettres comporte le singulier.

1Écrire le pluriel

Écrivez le pluriel brisé (avec les voyelles)

  1. قَلَمٌ →
  2. بَيْتٌ →
  3. رَجُلٌ →
  4. كِتَابٌ →
  5. وَلَدٌ →
  6. جَبَلٌ →

2Lieux et instruments

Écrivez le pluriel

  1. مَكْتَبٌ →
  2. مَدْرَسَةٌ →
  3. مَسْجِدٌ →
  4. مِفْتَاحٌ →
  5. مِصْبَاحٌ →
  6. مَلْعَبٌ →

3Personnes

Écrivez le pluriel

  1. طَالِبٌ →
  2. كَاتِبٌ →
  3. عَامِلٌ →
  4. وَزِيرٌ →
  5. صَدِيقٌ →
  6. فَقِيرٌ →

4Féminins

Écrivez le pluriel

  1. رِسَالَةٌ →
  2. جَرِيدَةٌ →
  3. حَدِيقَةٌ →
  4. نَافِذَةٌ →
  5. قَاعِدَةٌ →

5Retrouver le singulier

Écrivez le singulier

  1. دُرُوسٌ →
  2. أَبْوَابٌ →
  3. مَطَاعِمُ →
  4. رَسَائِلُ →
  5. جِيرَانٌ →
  6. مُدُنٌ →

6L'accord

Complétez avec l'adjectif entre parenthèses, accordé

  1. الْمَدَارِسُ … (جَدِيدٌ) →
  2. الطُّلَّابُ … (مُجْتَهِدٌ) →
  3. قَرَأْتُ كُتُبًا … (مُفِيدٌ) →
  4. فِي الْمَدِينَةِ حَدَائِقُ … (جَمِيلٌ) →

7Traduisez en arabe

Écrivez les phrases (avec les voyelles)

  1. Les amis sont à la maison →
  2. J'ai ouvert les portes →
  3. Les nouvelles lettres sont ici →
  4. Les étudiants lisent les journaux →

8Compréhension

Lisez et répondez

فِي الْمَدِينَةِ مَدَارِسُ كَثِيرَةٌ وَمَكَاتِبُ وَمَسَاجِدُ جَمِيلَةٌ. يَقْرَأُ الطُّلَّابُ الْكُتُبَ وَالْجَرَائِدَ فِي الْحَدَائِقِ، وَيَكْتُبُونَ الرَّسَائِلَ إِلَى أَصْدِقَائِهِمْ.

Questions :

  1. Traduisez le texte en français.
  2. Relevez les pluriels brisés et donnez leur singulier.
  3. Pourquoi les adjectifs كَثِيرَةٌ et جَمِيلَةٌ sont-ils au féminin singulier ?
💡 Conseil : quand vous apprenez un nom nouveau, apprenez-le avec son pluriel : كِتَابٌ (pl. كُتُبٌ), مَدْرَسَةٌ (pl. مَدَارِسُ).
