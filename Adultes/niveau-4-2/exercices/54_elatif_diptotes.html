Exercices — Cours 54 : L'élatif (comparatif et superlatif) et les diptotes

تَمَارِين

👋 Instructions : ces exercices accompagnent le cours 54. Pour le diptote, demandez-vous toujours : le mot est-il défini, ou premier terme d'une annexion ?

1Former l'élatif

Écrivez l'élatif (avec les voyelles) et traduisez

  1. سَهْلٌ →
  2. قَرِيبٌ →
  3. طَوِيلٌ →
  4. قَلِيلٌ →
  5. غَنِيٌّ →
  6. حَبِيبٌ →

2Comparer

Écrivez la phrase comparative

  1. La maison est plus grande que l'école. (الْبَيْتُ · الْمَدْرَسَةُ) →
  2. Mon frère est plus âgé que moi. →
  3. Cette leçon est plus facile que cette leçon-là. →
  4. Ce livre est meilleur que ce livre-là. →

3Superlatif

Traduisez en arabe

  1. la plus grande ville →
  2. la plus belle des maisons →
  3. le meilleur étudiant →
  4. la première leçon →

4Le féminin

Écrivez le féminin de l'élatif avec l'article

  1. الْأَكْبَرُ →
  2. الْأَصْغَرُ →
  3. الْأَعْلَى →
  4. الْأَفْضَلُ →

5Diptote ou non ?

Indiquez si le mot est diptote (oui / non) et justifiez

  1. أَحْمَدُ →
  2. مَدَارِسُ →
  3. كِتَابٌ →
  4. مُحَمَّدٌ →
  5. فَاطِمَةُ →
  6. أَحْمَرُ →
  7. طَالِبٌ →

6Déclinaison

Mettez le mot au cas indiqué (avec les voyelles)

  1. ذَهَبْتُ إِلَى … (مَكْتَبٌ, pluriel indéfini) →
  2. سَلَّمْتُ عَلَى … (أَحْمَدُ) →
  3. قَرَأْتُ كِتَابَ … (فَاطِمَةُ) →
  4. فِي … (مَدْرَسَةٌ, pluriel avec l'article) →
  5. رَأَيْتُ … (وَرْدَةٌ + حَمْرَاءُ) →

7Traduisez en arabe

Écrivez les phrases (avec les voyelles)

  1. Ma voiture est plus rapide que ta voiture →
  2. J'ai visité des villes nombreuses →
  3. C'est la plus grande ville du pays →
  4. Ils sont plus riches que nous →

8Compréhension

Lisez et répondez

زَارَتْ فَاطِمَةُ مَدِينَةً كَبِيرَةً. هَذِهِ الْمَدِينَةُ أَكْبَرُ مِنْ مَدِينَتِهَا، وَفِيهَا مَدَارِسُ أَكْثَرُ وَحَدَائِقُ أَجْمَلُ. هِيَ أَكْبَرُ مَدِينَةٍ فِي الْبِلَادِ.

Questions :

  1. Traduisez le texte en français.
  2. Relevez les élatifs et les diptotes.
  3. Pourquoi فَاطِمَةُ et مَدَارِسُ n'ont-ils pas de tanwīn ?
💡 Conseil : pour reconnaître un diptote, cherchez d'abord son schème : أَفْعَلُ, مَفَاعِلُ, فَعْلَاءُ sont toujours diptotes, et les noms de femmes aussi.
