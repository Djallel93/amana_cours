Cours 23 — Les lettres solaires (2) : ش ص ض ط ظ ل ن

Suite des lettres solaires : voici l’autre moitié, avec le ش de الشَّمْسُ et le ن de النَّجْمُ.

Objectifs

  • Connaître ش ص ض ط ظ ل ن
  • Lire un mot à lettre solaire : الشَّمْسُ
  • Écrire un nom défini solaire

Prérequis

Séance 22.

Nouveaux concepts

  • Lettres solaires : ش ص ض ط ظ ل ن (2e moitié)
  • Récapitulatif : 14 lettres solaires

Explication

Les quatorze lettres solaires sont : ت ث د ذ ر ز س ش ص ض ط ظ ل ن. Voici la seconde moitié en situation : شَمْسٌ devient الشَّمْسُ (ل muet).

IndéfiniDéfiniLectureSens
شَمْسٌالشَّمْسُ(ال) + شَّمْسُle soleil
نَجْمٌالنَّجْمُ(ال) + نَّجْمُl’étoile
نَهْرٌالنَّهْرُ(ال) + نَّهْرُle fleuve
شِتَاءٌالشِّتَاءُ(ال) + شِّتَاءُl’hiver
صَيْفٌالصَّيْفُ(ال) + صَّيْفُl’été

Dans un texte voyellé, regardez le ل : un سُكُونٌ signale le lunaire, une شَدَّةٌ sur la lettre suivante signale le solaire.

Activités guidées

  1. La classe lit les cinq mots du tableau en insistant sur la lettre doublée.
  2. Jeu des saisons : l’enseignant mime, les enfants disent le mot avec l’article.
  3. On colorie en jaune les mots solaires et en gris les lunaires dans une liste.
  4. Lecture des mots de la séance.

On lit les mots de la séance

Le ciel, l’eau et les saisons : chaque mot est écrit deux fois, sans article puis avec l’article. Lisez à voix haute et cherchez les lettres que le ل laisse doubler.

Lecture

شَمْسٌ نَجْمٌ نَهْرٌ
الشَّمْسُ النَّجْمُ النَّهْرُ
شِتَاءٌ صَيْفٌ
الشِّتَاءُ الصَّيْفُ
الْقَمَرُ الشَّمْسُ

Traduction
un soleil, une étoile, un fleuve
le soleil, l’étoile, le fleuve
un hiver, un été
l’hiver, l’été
la lune, le soleil

Avec l’article, la première lettre du mot se double et porte une شَدَّةٌ : le ش dans الشَّمْسُ et الشِّتَاءُ, le ن dans النَّجْمُ et النَّهْرُ, le ص dans الصَّيْفُ. Le ل de l’article est écrit, mais on ne l’entend pas.

Dans la dernière ligne, les deux mots se suivent mais ne se lisent pas de la même façon : الْقَمَرُ a un سُكُونٌ sur le ل, alors que الشَّمْسُ a une شَدَّةٌ sur le ش. La lune est lunaire, le soleil est solaire.

On s’entraîne

  1. Quelle lettre porte la شَدَّةٌ dans النَّهْرُ ? Entend-on le ل ?
  2. Lisez la quatrième ligne. Quel mot veut dire « l’hiver » et quel mot veut dire « l’été » ? Quelle lettre est doublée dans chacun ?
  3. Dans la dernière ligne, lequel des deux mots a un ل qui se prononce ? Comment le voyez-vous ?
  4. Jeu : mettez نَجْمٌ avec l’article. Quelle lettre se double ?
Corrigé
  1. C’est le ن qui porte la شَدَّةٌ. On n’entend pas le ل de l’article.
  2. الشِّتَاءُ est l’hiver, avec le ش doublé ; الصَّيْفُ est l’été, avec le ص doublé.
  3. C’est الْقَمَرُ : son ل porte un سُكُونٌ. Dans الشَّمْسُ, il n’y a pas de سُكُونٌ, mais une شَدَّةٌ sur le ش.
  4. On obtient النَّجْمُ : le ن reçoit une شَدَّةٌ.
