Bilan du niveau 3

Nom et prénom :   Date :

Évaluation finale du niveau 3, sur l’ensemble des séances. Elle donne accès au niveau 4-1 à partir de 12 / 20.

1Trouver le support de la هَمْزَةٌNotion : choix

Choisissez le support de la هَمْزَةٌ : أ, ؤ, ئ ou ء.

  1. رَ◌ْسٌ — voyelle avant : فَتْحَةٌ ; voyelle de la هَمْزَةٌ : سُكُونٌ
    أ ؤ ئ ء
  2. مُ◌ْمِنٌ — voyelle avant : ضَمَّةٌ ; voyelle de la هَمْزَةٌ : سُكُونٌ
    أ ؤ ئ ء
  3. هَادِ◌ٌ — voyelle avant : كَسْرَةٌ
    أ ؤ ئ ء
  4. دَوَا◌ٌ — voyelle avant : أَلِفٌ long
    أ ؤ ئ ء

4Lire le texteNotion : lecture suivie

Lisez le texte à voix haute, puis répondez aux questions en français.

هَٰذِهِ لَيْلَى. هِيَ طَالِبَةٌ جَدِيدَةٌ فِي الْمَدْرَسَةِ. حَقِيبَتُهَا كَبِيرَةٌ.

  1. Qui est Layla ?
  2. Où est-elle ?
  3. Comment est son sac ?

Corrigé (enseignant)
  • Exercice 1 : 1. أ ; 2. ؤ ; 3. ئ ; 4. ء
  • Exercice 2 : الْقَمَرُ → lunaire ; الشَّمْسُ → solaire ; الْبَابُ → lunaire ; الرِّيحُ → solaire ; الْكَاتِبُ → lunaire
  • Exercice 3 : 1. قِطَارًا ; 2. مَاءً ; 3. سَيَّارَةً ; 4. مَقْهًى
  • Exercice 4 : traduction : Voici Layla. Elle est une nouvelle étudiante à l’école. Son sac est grand. — réponses : 1. une nouvelle étudiante ; 2. à l’école ; 3. grand
  • Exercice 5 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 6 : م ن ب ر → مِنْبَرٌ ; م ك ت ب → مَكْتَبٌ ; ذ ل ك → ذَٰلِكَ ; س ك ر → سُكَّرٌ ; ي و م → يَوْمٌ
  • Exercice 7 : وَاحِدٌ → و - ا - ح - د ; سِتَارَةٌ → س - ت - ا - ر - ة ; رِحْلَةٌ → ر - ح - ل - ة ; فِرَاشٌ → ف - ر - ا - ش
  • Exercice 8 : أَحْمَرُ ; جَدٌّ ; مِنْبَرٌ ; كُبْرَى ; كَبِيرٌ ; ثَلْجٌ
  • Exercice 9 : ثَلْجٌ = neige ; سَلَامٌ = paix ; جَرَائِدُ = journaux ; لَٰكِنْ = mais ; إِصْبَعٌ = doigt ; مَاءٌ = eau
  • Exercice 10 : trait = خَطٌّ ; cela = ذَٰلِكَ ; difficile = صَعْبٌ ; dix = عَشَرَةٌ ; mère = أُمٌّ
