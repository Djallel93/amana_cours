  • Exercice 4 : 1. الْقَلَمُ ; 2. الْبَحْرُ ; 3. النَّهْرُ ; 4. الرِّيحُ

  • Exercice 7 : ق ب ع ة → قُبَّعَةٌ ; ه ا ت ف → هَاتِفٌ ; م ن → مِنْ ; ن ج م → نَجْمٌ
  • Exercice 8 : شَمْسٌ → ش - م - س ; قَارِئٌ → ق - ا - ر - ئ ; أَخْضَرُ → أ - خ - ض - ر ; وُضُوءٌ → و - ض - و - ء
