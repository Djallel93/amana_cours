Les nombres ordinaux en arabe

الأَعْداد التَّرْتيبِيَّة
Bienvenue dans cette leçon sur les nombres ordinaux en arabe ! Les nombres ordinaux (premier, deuxième, troisième...) servent à indiquer la position, le rang ou l'ordre des éléments. Contrairement aux nombres cardinaux qui répondent à la question "combien ?", les ordinaux répondent à "lequel dans l'ordre ?". En arabe, ces nombres ont des formes particulières et s'accordent en genre avec le nom qu'ils qualifient.
💡 Prérequis : Avant d'étudier cette partie, assurez-vous de connaître les nombres cardinaux ainsi que les règles du masculin et du féminin.

🎯 Qu'est-ce qu'un nombre ordinal ?

Définition : Les nombres ordinaux indiquent la position ou le rang dans une séquence ordonnée. En français : premier, deuxième, troisième, etc. En arabe : الأَوَّل، الثَّانِي، الثَّالِث

📝 Exemples d'utilisation :

  • الدَّرْسُ الأَوَّلُ → La première leçon
  • الطَّابِقُ الثَّالِثُ → Le troisième étage
  • الصَّفُّ الخَامِسُ → La cinquième classe
  • القَرْنُ العِشْرُونَ → Le vingtième siècle

📊 Formation des nombres ordinaux

A. De 1 à 10 : Formes irrégulières

Les dix premiers nombres ordinaux ont des formes spéciales qui doivent être mémorisées. Ils suivent le schème فَاعِل pour la plupart.

Chiffre Masculin Féminin Français
1er أَوَّلُ أُولَى premier / première
2e ثَانٍ ثَانِيَةٌ deuxième / seconde
3e ثَالِثٌ ثَالِثَةٌ troisième
4e رَابِعٌ رَابِعَةٌ quatrième
5e خَامِسٌ خَامِسَةٌ cinquième
6e سَادِسٌ سَادِسَةٌ sixième
7e سَابِعٌ سَابِعَةٌ septième
8e ثَامِنٌ ثَامِنَةٌ huitième
9e تَاسِعٌ تَاسِعَةٌ neuvième
10e عَاشِرٌ عَاشِرَةٌ dixième
⚠️ Cas particuliers :
  • أَوَّل (premier) et أُولَى (première) sont complètement irréguliers
  • ثَانٍ (deuxième) perd son nûn final quand il est défini ou dans une annexion : الثَّانِي

📝 Exemples en phrases :

  • الدَّرْسُ الأَوَّلُ → La première leçon (masculin)
  • المَرَّةُ الأُولَى → La première fois (féminin)
  • الكِتَابُ الثَّالِثُ → Le troisième livre (masculin)
  • الصَّفْحَةُ الخَامِسَةُ → La cinquième page (féminin)
  • الطَّالِبُ السَّابِعُ → Le septième étudiant (masculin)

B. De 11 à 19 : Construction particulière

Pour les nombres ordinaux de 11 à 19, on utilise une construction spéciale : le nombre cardinal suivi de l'ordinal correspondant à l'unité.

Formule : حَادِي عَشَرَ (onzième) = حَادِي (de واحد) + عَشَرَ (dix)

Chiffre Masculin Féminin Français
11e حَادِي عَشَرَ حَادِيَةَ عَشْرَةَ onzième
12e ثَانِيَ عَشَرَ ثَانِيَةَ عَشْرَةَ douzième
13e ثَالِثَ عَشَرَ ثَالِثَةَ عَشْرَةَ treizième
14e رَابِعَ عَشَرَ رَابِعَةَ عَشْرَةَ quatorzième
15e خَامِسَ عَشَرَ خَامِسَةَ عَشْرَةَ quinzième
16e سَادِسَ عَشَرَ سَادِسَةَ عَشْرَةَ seizième
17e سَابِعَ عَشَرَ سَابِعَةَ عَشْرَةَ dix-septième
18e ثَامِنَ عَشَرَ ثَامِنَةَ عَشْرَةَ dix-huitième
19e تَاسِعَ عَشَرَ تَاسِعَةَ عَشْرَةَ dix-neuvième

📝 Exemples en phrases :

  • القَرْنُ الحَادِي عَشَرَ → Le onzième siècle (masculin)
  • السَّنَةُ الثَّالِثَةَ عَشْرَةَ → La treizième année (féminin)
  • الطَّابِقُ الخَامِسَ عَشَرَ → Le quinzième étage (masculin)

C. Les dizaines (20, 30, 40...)

Pour les dizaines, on utilise le schème فَاعِل avec la forme plurielle.

Chiffre Arabe Français
20e عِشْرُونَ vingtième
30e ثَلاثُونَ trentième
40e أَرْبَعُونَ quarantième
50e خَمْسُونَ cinquantième
60e سِتُّونَ soixantième
70e سَبْعُونَ soixante-dixième
80e ثَمَانُونَ quatre-vingtième
90e تِسْعُونَ quatre-vingt-dixième
100e مِئَةٌ centième
1000e أَلْفٌ millième
💡 À noter : Pour les dizaines, on utilise généralement la forme du nombre cardinal. La distinction entre cardinal et ordinal est souvent faite par le contexte.

D. Nombres composés (21-99)

Pour les nombres composés, on combine l'ordinal de l'unité avec le cardinal de la dizaine, reliés par وَ (et).

Formule : Ordinal de l'unité + وَ + Cardinal de la dizaine

📝 Exemples :

  • الحَادِي وَالعِشْرُونَ → Le vingt-et-unième
  • الثَّالِثُ وَالثَّلاثُونَ → Le trente-troisième
  • الخَامِسُ وَالأَرْبَعُونَ → Le quarante-cinquième
  • السَّابِعُ وَالسِّتُّونَ → Le soixante-septième
  • التَّاسِعُ وَالتِّسْعُونَ → Le quatre-vingt-dix-neuvième

📝 En phrases complètes :

  • هَذَا الكِتَابُ الثَّالِثُ وَالعِشْرُونَ → Ceci est le vingt-troisième livre
  • في القَرْنِ الحَادِي وَالعِشْرِينَ → Au vingt-et-unième siècle
  • السَّنَةُ الخَامِسَةُ وَالأَرْبَعُونَ → La quarante-cinquième année

📝 Position et accord des nombres ordinaux

A. Position dans la phrase

Règle importante : Les nombres ordinaux se placent après le nom qu'ils qualifient, comme tous les adjectifs en arabe.

📝 Structure : Nom + Ordinal

  • الدَّرْسُ الأَوَّلُ → La première leçon (littéralement : la leçon la première)
  • الصَّفُّ الثَّانِي → La deuxième classe
  • المَرَّةُ الثَّالِثَةُ → La troisième fois

B. Accord en genre

Les nombres ordinaux s'accordent en genre avec le nom qu'ils qualifient.

📝 Plus d'exemples d'accord :

  • Masculin : الشَّهْرُ السَّابِعُ → Le septième mois
  • Féminin : اللَّيْلَةُ السَّابِعَةُ → La septième nuit
  • Masculin : اليَوْمُ التَّاسِعُ → Le neuvième jour
  • Féminin : السَّاعَةُ التَّاسِعَةُ → La neuvième heure

C. Accord en définition

Le nombre ordinal prend l'article défini ال quand le nom est défini, créant ainsi un accord en définition.

✅ Correct :

  • الدَّرْسُ الأَوَّلُ → La première leçon (les deux sont définis)
  • الكِتَابُ الثَّالِثُ → Le troisième livre (les deux sont définis)

❌ Incorrect :

  • الدَّرْسُ أَوَّلُ → (sans ال sur l'ordinal)

D. Déclinaison (cas grammaticaux)

Les nombres ordinaux se déclinent selon les trois cas grammaticaux en arabe : nominatif, accusatif et génitif.

🎓 Usages particuliers

A. Dans les dates et le calendrier

📅 Exemples avec les dates :

  • اليَوْمُ الأَوَّلُ مِنْ يَنَايِرَ → Le premier jour de janvier
  • الشَّهْرُ الخَامِسُ → Le cinquième mois (mai)
  • السَّنَةُ الأُولَى → La première année
  • القَرْنُ الحَادِي وَالعِشْرُونَ → Le vingt-et-unième siècle

B. Dans l'éducation

🎒 Exemples scolaires :

  • الصَّفُّ الأَوَّلُ الابْتِدَائِي → La première année primaire
  • الفَصْلُ الدِّرَاسِيُّ الثَّانِي → Le deuxième semestre
  • السَّنَةُ الجَامِعِيَّةُ الثَّالِثَةُ → La troisième année universitaire
  • الدَّرْسُ الخَامِسُ → La cinquième leçon

C. Dans les titres et les rangs

👑 Exemples avec des titres :

  • لُويس الرَّابِعَ عَشَرَ → Louis XIV (Louis quatorze)
  • الحَرْبُ العَالَمِيَّةُ الثَّانِيَةُ → La Deuxième Guerre mondiale
  • الجُزْءُ الأَوَّلُ → La première partie
  • المَرْحَلَةُ الثَّالِثَةُ → La troisième étape

D. Dans les adresses et les lieux

🏢 Exemples avec des lieux :

  • الطَّابِقُ الأَوَّلُ → Le premier étage
  • الغُرْفَةُ الثَّالِثَةُ → La troisième chambre
  • الشَّارِعُ الخَامِسُ → La cinquième rue
  • المَبْنَى السَّابِعُ → Le septième bâtiment

🔍 Distinctions importantes

Ordinal vs Cardinal

Différence clé :

  • Cardinal : répond à "combien ?" → ثَلاثَةُ كُتُبٍ (trois livres)
  • Ordinal : répond à "lequel ?" → الكِتَابُ الثَّالِثُ (le troisième livre)
Type Exemple Traduction
Cardinal عِنْدِي خَمْسَةُ كُتُبٍ J'ai cinq livres
Ordinal أَقْرَأُ الكِتَابَ الخَامِسَ Je lis le cinquième livre
Cardinal دَرَسْتُ سَبْعَ سَاعَاتٍ J'ai étudié sept heures
Ordinal في السَّاعَةِ السَّابِعَةِ À la septième heure

📚 Résumé des règles essentielles

🎯 Points clés à retenir :

  • Position : L'ordinal se place après le nom
  • Accord en genre : Masculin avec masculin, féminin avec féminin
  • Accord en définition : Si le nom a ال, l'ordinal aussi
  • 1-10 : Formes irrégulières à mémoriser
  • 11-19 : Construction avec l'unité ordinale + عَشَرَ/عَشْرَةَ
  • 21-99 : Ordinal de l'unité + وَ + cardinal de la dizaine
  • Déclinaison : Les ordinaux suivent les trois cas grammaticaux
💡 Astuce pour mémoriser : Les premiers ordinaux (1-10) suivent le schème فَاعِل (fā'il) : ثَالِث، رَابِع، خَامِس... Cette régularité facilite leur mémorisation !

✨ Exemples récapitulatifs :

  • هَذَا الدَّرْسُ الأَوَّلُ في النَّحْوِ → C'est la première leçon de grammaire
  • أَسْكُنُ في الطَّابِقِ السَّادِسِ → J'habite au sixième étage
  • نَحْنُ في القَرْنِ الحَادِي وَالعِشْرِينَ → Nous sommes au vingt-et-unième siècle
  • قَرَأْتُ الصَّفْحَةَ الثَّالِثَةَ عَشْرَةَ → J'ai lu la treizième page
