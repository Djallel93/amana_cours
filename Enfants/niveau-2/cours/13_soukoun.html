Cours 13 — Le petit rond : le sukūn

Le sukūn est un petit rond sur une lettre. Il veut dire : « pas de voyelle ici ! » On lit alors la lettre très vite, collée à la précédente.

Objectifs

  • Lire une syllabe fermée par un sukūn
  • Lire des mots courts contenant un sukūn

Prérequis

Les voyelles brèves (fatḥa, ḍamma, kasra).

Nouveaux concepts

  • Le sukūn : absence de voyelle
  • La syllabe fermée : consonne + voyelle + consonne

Activités guidées

  1. Lire le mot. L'enseignant lit un mot ; repérez le sukūn et dites quelle consonne il ferme.
  2. Compter les syllabes. Frappez dans les mains à chaque syllabe.
  3. Dictée de syllabes fermées. L'enseignant dit une syllabe ; écrivez-la avec le sukūn.

Exercices

Dans le fichier de chaque lettre :
