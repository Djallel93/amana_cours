Corrigé (enseignant)
  • Exercice 1 : و dans وجه : début ; ك dans كتاب : début ; ن dans لبن : fin ; و dans وطن : début ; ي dans طريق : milieu.
  • Exercice 2 : ـبـ : médiane ; صـ : initiale ; ـغـ : médiane ; ـخ : finale ; ص : isolée. (Pour une lettre qui ne se lie pas à la suivante, la forme initiale s'écrit comme la forme isolée : accepter les deux réponses.)
  • Exercice 3 : حديث = ح د ي ث ; وقت = و ق ت ; غيم = غ ي م.
  • Exercice 4 : ف ي ل = فيل ; ت ا ج = تاج ; ق ف ص = قفص.
