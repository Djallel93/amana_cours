Révision 1 — les formes des lettres

Révisons les visages des lettres !

1Où est la lettre ?

Cherche la lettre dans le mot. Coche où elle est.

MotLettrePosition
يومي début milieu fin
سهلل début milieu fin
كثيرك début milieu fin
درسر début milieu fin

2Je sépare les lettres

Écris les lettres une par une.

  • سفر →
  • نخل →
  • سمك →

3Je donne la main aux lettres

Écris le mot en reliant les lettres.

  • س م ك →
  • س ي ف →
  • ي و م →

4Quel visage ?

Où la lettre se trouve-t-elle dans le mot ? Coche.

FormePosition
ـف début milieu fin

Corrigé (enseignant)
  • Exercice 1 : ي dans يوم ; ل dans سهل ; ك dans كثير ; ر dans درس (vérifier la position sur le mot).
  • Exercice 2 : سفر = س ف ر ; نخل = ن خ ل ; سمك = س م ك
  • Exercice 3 : س م ك = سمك ; س ي ف = سيف ; ي و م = يوم
  • Exercice 4 : formes avec liaison à droite seulement (ـ à gauche du signe) : fin ; des deux côtés : milieu ; avec liaison à gauche seulement : début.
