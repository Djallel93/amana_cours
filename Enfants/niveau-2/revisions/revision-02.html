Révision 2 — voyelles brèves et signes

Révisons les petits signes : voyelles, rond, shadda et tanwīn !

1Je lis les syllabes

Lis à voix haute.

نِبَّدُرُمْبِمْكَّرُّمَنْتِمْ

2Je lis les mots

Lis chaque mot, puis relie-le à son sens.

  • كَلْب
  • بَحْر
  • دُبّ
  • دَرْس
  • جَدّ
  • le grand-père
  • la leçon
  • le chien
  • l'ours
  • la mer

3Je connais les signes

Relie chaque signe à son nom.

  • ـً
  • ـْ
  • ـٌ
  • ـٍ
  • ـَ
  • la kasratān
  • la fatḥatān
  • le sukūn
  • la ḍammatān
  • la fatḥa

4J'écris ce que j'entends

Ton enseignant dit six syllabes. Écris-les.

5Je copie

Copiez les mots avec tous les signes.

سُكَّر

حُبّ

دَرْس

شَمْس

Corrigé (enseignant)
  • Exercice 2 : كَلْب = le chien ; بَحْر = la mer ; دُبّ = l'ours ; دَرْس = la leçon ; جَدّ = le grand-père
  • Exercice 3 : ـً = la fatḥatān ; ـْ = le sukūn ; ـٌ = la ḍammatān ; ـٍ = la kasratān ; ـَ = la fatḥa
