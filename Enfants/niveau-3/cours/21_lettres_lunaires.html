Cours 21 — Les lettres lunaires

Les quatorze lettres lunaires font prononcer le ل de l’article, comme dans الْقَمَرُ, « la lune ». On retrouve aussi les jours de la semaine.

Objectifs

  • Connaître les 14 lettres lunaires
  • Écrire l’article avec un ل à سُكُونٌ devant ces lettres
  • Lire les jours de la semaine à lettre lunaire

Prérequis

Séance 20.

Nouveaux concepts

  • 14 lettres lunaires
  • Le ل porte un سُكُونٌ et se prononce
  • Les jours الْأَحَدُ, الْأَرْبِعَاءُ, الْخَمِيسُ, الْجُمُعَةُ

Explication

Voici les quatorze lettres lunaires. Pour les retenir, on utilise une phrase classique dont chaque mot commence par l’une d’elles ou presque : اِبْغِ حَجَّكَ وَخَفْ عَقِيمَهُ. Les lettres sont : ا ب ج ح خ ع غ ف ق ك م ه و ي. Il suffit de savoir que أ, إ et la هَمْزَةٌ en général font aussi partie du groupe.

DéfiniLectureSens
الْقَمَرُالْ + قَمَرُla lune
الْبَحْرُالْ + بَحْرُla mer
الْجَبَلُالْ + جَبَلُla montagne
الْيَوْمُالْ + يَوْمُle jour, aujourd’hui
الْعَامُالْ + عَامُl’année
الْأُسْبُوعُالْ + أُسْبُوعُla semaine

Devant ces mots, l’article s’écrit toujours الْ : أَلِفٌ, لَامٌ avec سُكُونٌ. Pour les jours de la semaine, on les écrit presque toujours avec l’article. Aujourd’hui, quatre jours ont une lettre lunaire : الْأَحَدُ (dimanche), الْأَرْبِعَاءُ (mercredi), الْخَمِيسُ (jeudi) et الْجُمُعَةُ (vendredi).

Dans الْأَحَدُ et الْأَرْبِعَاءُ, la هَمْزَةٌ initiale est une vraie هَمْزَةٌ (قَطْعٌ) : elle reste prononcée après l’article.

Activités guidées

  1. La classe récite la phrase mnémotechnique : اِبْغِ حَجَّكَ وَخَفْ عَقِيمَهُ.
  2. L’enseignant lit un mot, la classe dit s’il commence par une lettre lunaire.
  3. On récite les quatre jours lunaires ; on écrit celui d’aujourd’hui.
  4. Lecture des mots de la séance.
  5. Jeu : on récite ensemble اِبْغِ حَجَّكَ وَخَفْ عَقِيمَهُ, comme une comptine.
