Évaluation diagnostique — niveau 3

Nom et prénom :   Date :

Cette évaluation sert à situer chaque apprenant avant le niveau 3 : elle ne compte pas dans la note finale. Les exercices reprennent les acquis des niveaux 1 et 2 (lettres, voyelles, sukūn, shadda, tanwīn).

1Lettres qui ne se lient pasNotion : reconnaissance

Cochez les lettres qui ne se lient pas à la suivante.

  1. ب
  2. ر
  3. د
  4. م
  5. و
  6. ن
  7. ز
  8. ع
  9. ا

2Lire des motsNotion : lecture

Lisez à voix haute, sans épeler.

كِتَابٌقَلَمٌدَفْتَرٌلَوْحٌطَالِبٌمُعَلِّمٌدَرْسٌصَفٌّوَرَقٌمَكْتَبٌ

3Construire des motsNotion : construction

Assemblez les lettres pour écrire chaque mot, avec ses voyelles.

مدير

Sens : directeur

زميل

Sens : camarade

جرس

Sens : sonnette

جواب

Sens : réponse

4Découper en syllabesNotion : déconstruction

Découpez chaque mot en syllabes : écrivez les syllabes séparées par un tiret.

حَرْفٌ — lettre

رَسْمٌ — dessin

رَقْمٌ — chiffre

خَطٌّ — trait

5Dictée de motsNotion : dictée

Votre enseignant dicte 5 mots. Écrivez-les, avec leurs voyelles.

6Relier le mot et son sensNotion : vocabulaire

Reliez chaque mot à son sens.

  • سَرِيرٌ
  • كُرْسِيٌّ
  • كُوبٌ
  • صَحْنٌ
  • سِكِّينٌ
  • صُنْدُوقٌ
  • boîte
  • lit
  • chaise
  • couteau
  • assiette
  • verre
Corrigé (enseignant)
  • Exercice 1 : ر ; د ; و ; ز ; ا
  • Exercice 2 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 3 : م د ي ر → مُدِيرٌ ; ز م ي ل → زَمِيلٌ ; ج ر س → جَرَسٌ ; ج و ا ب → جَوَابٌ
  • Exercice 4 : حَرْفٌ → حَرْ – فٌ (2) ; رَسْمٌ → رَسْ – مٌ (2) ; رَقْمٌ → رَقْ – مٌ (2) ; خَطٌّ → خَطْ – طٌ (2)
  • Exercice 5 : سُكَّرٌ ; حَبٌّ ; جَوٌّ ; مِفْتَاحٌ ; هَاتِفٌ
  • Exercice 6 : سَرِيرٌ = lit ; كُرْسِيٌّ = chaise ; كُوبٌ = verre ; صَحْنٌ = assiette ; سِكِّينٌ = couteau ; صُنْدُوقٌ = boîte
