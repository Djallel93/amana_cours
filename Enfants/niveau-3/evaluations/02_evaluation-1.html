Corrigé (enseignant)
  • Exercice 1 : غُرْفَةٌ → ة ; بَيْتٌ → ت ; وَجْهٌ → ه ; مُوسَى → ى ; مَدْرَسَةٌ → ة
  • Exercice 2 : 1. قِطَارًا ; 2. سَيَّارَةً ; 3. مَقْهًى
  • Exercice 3 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 4 : س ك ي ن → سِكِّينٌ ; ص ع ب → صَعْبٌ ; ق ص ي ر → قَصِيرٌ ; س ف ي ن ة → سَفِينَةٌ ; س ل م ى → سَلْمَى
  • Exercice 5 : مَلَاكٌ → م - ل - ا - ك ; طَرِيقٌ → ط - ر - ي - ق ; بَابٌ → ب - ا - ب ; مَتَى → م - ت - ى
  • Exercice 6 : جَوٌّ ; طَوِيلٌ ; غُرْفَةٌ ; شَارِعٌ ; كَبِيرٌ ; هَاتِفٌ
  • Exercice 7 : قَصِيرٌ = court ; سَفِينَةٌ = bateau ; صَعْبٌ = difficile ; هُوَ = il ; لَوْحٌ = tableau ; زَوْجَةٌ = épouse
  • Exercice 8 : permis = حَلَالٌ ; temps, air = جَوٌّ ; train = قِطَارٌ ; téléphone = هَاتِفٌ ; couteau = سِكِّينٌ
