Bilan du niveau 3

Nom et prénom :   Date :

Évaluation finale du niveau 3, sur l’ensemble des séances. Elle donne accès au niveau 4-1 à partir de 12 / 20.

1Trouver le support de la hamzaNotion : choix

Choisissez le support de la hamza : أ, ؤ, ئ ou ء.

  1. رَ◌ْسٌ — voyelle avant : fatḥa ; voyelle de la hamza : sukūn
    أ ؤ ئ ء
  2. مُ◌ْمِنٌ — voyelle avant : ḍamma ; voyelle de la hamza : sukūn
    أ ؤ ئ ء
  3. هَادِ◌ٌ — voyelle avant : kasra
    أ ؤ ئ ء
  4. دَوَا◌ٌ — voyelle avant : voyelle longue
    أ ؤ ئ ء

4Lire le texteNotion : lecture suivie

Lisez le texte à voix haute, puis répondez aux questions en français.

هَٰذِهِ لَيْلَى. هِيَ طَالِبَةٌ جَدِيدَةٌ فِي الْمَدْرَسَةِ. حَقِيبَتُهَا كَبِيرَةٌ.

  1. Qui est Layla ?
  2. Où est-elle ?
  3. Comment est son sac ?

5Lire des motsNotion : lecture

Lisez à voix haute, sans épeler.

Note : …… / 20

Corrigé (enseignant)
  • Exercice 1 : 1. أ ; 2. ؤ ; 3. ئ ; 4. ء
  • Exercice 2 : الْقَمَرُ → lunaire ; الشَّمْسُ → solaire ; الْبَابُ → lunaire ; الرِّيحُ → solaire ; الْكَاتِبُ → lunaire
  • Exercice 3 : 1. قِطَارًا ; 2. مَاءً ; 3. سَيَّارَةً ; 4. مَقْهًى
  • Exercice 4 : traduction : Voici Layla. Elle est une nouvelle étudiante à l’école. Son sac est grand. — réponses : 1. une nouvelle étudiante ; 2. à l’école ; 3. grand
  • Exercice 5 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 6 : ح م ا م → حَمَّامٌ ; ش ي ء → شَيْءٌ ; ع ي س ى → عِيسَى ; و ج ه → وَجْهٌ ; ط ف ل → طِفْلٌ
  • Exercice 7 : قَرِيبٌ → ق - ر - ي - ب ; وَاحِدٌ → و - ا - ح - د ; هُوَ → ه - و ; أَحْمَرُ → أ - ح - م - ر
  • Exercice 8 : فُطُورٌ ; أَسْوَدُ ; شِتَاءٌ ; وَرَقٌ ; أَمَامَ ; الْجُمُعَةُ
  • Exercice 9 : مَطَارٌ = aéroport ; أَمَامَ = devant ; مَقْهًى = café ; مِحْرَابٌ = mihrab ; أُذُنٌ = oreille ; طَاوِلَةٌ = table
  • Exercice 10 : neuf = تِسْعَةٌ ; tante paternelle = عَمَّةٌ ; couteau = سِكِّينٌ ; mihrab = مِحْرَابٌ ; chose = شَيْءٌ
