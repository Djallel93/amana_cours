Exercices niveau 3 — Cours 8 : Distinguer ة, ت et ه en fin de mot

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Prévoyez des temps de jeu à l’oral en plus des exercices écrits, et plusieurs pauses : une page peut se faire en deux fois.

Reconnaître et classer

1Classer selon la dernière lettreNotion : classement

Cochez la dernière lettre de chaque mot.

Motةته
غُرْفَةٌ
بَيْتٌ
وَجْهٌ
حَدِيقَةٌ
صَوْتٌ
نَافِذَةٌ

2Choisir la bonne terminaisonNotion : choix

Choisissez la lettre finale qui convient.

  1. غُرْفَـ… (chambre)
    ة ت ه
  2. بَيْـ… (maison)
    ة ت ه
  3. وَجْـ… (visage)
    ة ت ه
  4. حَدِيقَـ… (jardin)
    ة ت ه

Construire et déconstruire

3Construire des motsNotion : construction

Assemblez les lettres pour écrire chaque mot, avec ses voyelles.

غرفة

Sens : chambre

نافذة

Sens : fenêtre

حمام

Sens : salle de bain

سقف

Sens : plafond

4Déconstruire des motsNotion : déconstruction

Séparez le mot en lettres : écrivez chaque lettre isolément, de droite à gauche.

حَدِيقَةٌ — jardin

مَطْبَخٌ — cuisine

بَيْتٌ — maison

صَوْتٌ — voix

Lire

5Lire les mots de la séanceNotion : lecture

Lisez à voix haute, sans épeler.

غُرْفَةٌحَدِيقَةٌنَافِذَةٌمَطْبَخٌحَمَّامٌبَيْتٌسَقْفٌصَوْتٌزَيْتٌوَجْهٌ

6Lire des phrasesNotion : lecture

Lisez chaque phrase à voix haute, puis donnez-en le sens.

  1. بَيْتٌ كَبِيرٌ
  2. غُرْفَةٌ صَغِيرَةٌ
  3. حَدِيقَةٌ جَدِيدَةٌ
  4. نَافِذَةٌ قَدِيمَةٌ

Dicter et écrire

7Dictée de motsNotion : dictée

8Dictée de phrasesNotion : dictée

Votre enseignant dicte 2 phrases. Écrivez-les, avec leurs voyelles.

Corrigé (enseignant)
  • Exercice 1 : غُرْفَةٌ → ة ; بَيْتٌ → ت ; وَجْهٌ → ه ; حَدِيقَةٌ → ة ; صَوْتٌ → ت ; نَافِذَةٌ → ة
  • Exercice 2 : 1. ة ; 2. ت ; 3. ه ; 4. ة
  • Exercice 3 : غ ر ف ة → غُرْفَةٌ ; ن ا ف ذ ة → نَافِذَةٌ ; ح م ا م → حَمَّامٌ ; س ق ف → سَقْفٌ
  • Exercice 4 : حَدِيقَةٌ → ح - د - ي - ق - ة ; مَطْبَخٌ → م - ط - ب - خ ; بَيْتٌ → ب - ي - ت ; صَوْتٌ → ص - و - ت
  • Exercice 5 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 6 : traductions : 1. une grande maison ; 2. une petite chambre ; 3. un jardin neuf ; 4. une fenêtre ancienne
  • Exercice 7 : حَدِيقَةٌ ; مَطْبَخٌ ; بَيْتٌ ; صَوْتٌ ; وَجْهٌ
  • Exercice 8 : بَيْتٌ كَبِيرٌ ; غُرْفَةٌ صَغِيرَةٌ
  • Exercice 9 : غُرْفَةٌ = chambre ; حَدِيقَةٌ = jardin ; نَافِذَةٌ = fenêtre ; مَطْبَخٌ = cuisine ; حَمَّامٌ = salle de bain ; بَيْتٌ = maison ; سَقْفٌ = plafond ; صَوْتٌ = voix
  • Exercice 10 : fenêtre = نَافِذَةٌ ; salle de bain = حَمَّامٌ ; plafond = سَقْفٌ ; huile = زَيْتٌ
