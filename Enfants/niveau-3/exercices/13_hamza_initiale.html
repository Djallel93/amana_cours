Exercices niveau 3 — Cours 13 : La هَمْزَةٌ au début du mot : أ إ آ

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Prévoyez des temps de jeu à l’oral en plus des exercices écrits, et plusieurs pauses : une page peut se faire en deux fois.

Nom et prénom :   Date :

Reconnaître et classer

1Choisir le bon أَلِفٌNotion : choix

Choisissez l’أَلِفٌ qui convient.

  1. هَمْزَةٌ + فَتْحَةٌ en début de mot
    أ إ
  2. هَمْزَةٌ + كَسْرَةٌ en début de mot
    أ إ
  3. هَمْزَةٌ + ضَمَّةٌ en début de mot
    أ إ
  4. هَمْزَةٌ + أَلِفٌ long
    آ أ

2Classer les motsNotion : classement

Cochez la forme de l’أَلِفٌ de chaque mot.

Construire et déconstruire

3Construire des motsNotion : construction

Assemblez les lettres pour écrire chaque mot, avec ses voyelles.

أب

Sens : père

أخ

Sens : frère

أذن

Sens : oreille

إصبع

Sens : doigt

آلة

Sens : machine

4Déconstruire des motsNotion : déconstruction

Séparez le mot en lettres : écrivez chaque lettre isolément, de droite à gauche.

أُمٌّ — mère

أُخْتٌ — sœur

أَنْفٌ — nez

إِبْرَةٌ — aiguille

آذَانٌ — oreilles

Lire

5Lire les mots de la séanceNotion : lecture

Lisez à voix haute, sans épeler.

أَبٌأُمٌّأَخٌأُخْتٌأَنْفٌأُذُنٌإِصْبَعٌإِبْرَةٌآذَانٌآلَةٌ

6Lire des phrasesNotion : lecture

Lisez chaque phrase à voix haute, puis donnez-en le sens.

  1. هَٰذَا أَخٌ صَغِيرٌ
  2. هَٰذِهِ أُخْتٌ كَبِيرَةٌ
  3. هَٰذِهِ إِبْرَةٌ صَغِيرَةٌ
  4. هَٰذَا أَنْفٌ طَوِيلٌ

Dicter et écrire

7Dictée de motsNotion : dictée

Votre enseignant dicte 5 mots. Écrivez-les, avec leurs voyelles.

8Dictée de phrasesNotion : dictée

Votre enseignant dicte 2 phrases. Écrivez-les, avec leurs voyelles.

Corrigé (enseignant)
  • Exercice 1 : 1. أ ; 2. إ ; 3. أ ; 4. آ
  • Exercice 2 : أَخٌ → أ ; إِبْرَةٌ → إ ; آلَةٌ → آ ; أُخْتٌ → أ ; إِصْبَعٌ → إ ; آذَانٌ → آ
  • Exercice 3 : أ ب → أَبٌ ; أ خ → أَخٌ ; أ ذ ن → أُذُنٌ ; إ ص ب ع → إِصْبَعٌ ; آ ل ة → آلَةٌ
  • Exercice 4 : أُمٌّ → أ - م ; أُخْتٌ → أ - خ - ت ; أَنْفٌ → أ - ن - ف ; إِبْرَةٌ → إ - ب - ر - ة ; آذَانٌ → آ - ذ - ا - ن
  • Exercice 5 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 6 : traductions : 1. c’est un petit frère ; 2. c’est une grande sœur ; 3. c’est une petite aiguille ; 4. c’est un long nez
  • Exercice 7 : أُمٌّ ; أُخْتٌ ; أُذُنٌ ; إِبْرَةٌ ; آلَةٌ
  • Exercice 8 : هَٰذَا أَخٌ صَغِيرٌ ; هَٰذِهِ أُخْتٌ كَبِيرَةٌ
  • Exercice 9 : أَبٌ = père ; أُمٌّ = mère ; أَخٌ = frère ; أُخْتٌ = sœur ; أَنْفٌ = nez ; أُذُنٌ = oreille ; إِصْبَعٌ = doigt ; إِبْرَةٌ = aiguille
  • Exercice 10 : frère = أَخٌ ; nez = أَنْفٌ ; doigt = إِصْبَعٌ ; oreilles = آذَانٌ
