Exercices niveau 3 — Cours 18 : Les nombres de 1 à 10 et révision de la hamza

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Prévoyez des temps de jeu à l’oral en plus des exercices écrits, et plusieurs pauses : une page peut se faire en deux fois.

Corrigé (enseignant)
  • Exercice 1 : أَرْبَعَةٌ → hamza ; سِتَّةٌ → shadda ; ثَلَاثَةٌ → ligature لا
  • Exercice 2 : ث ل ا ث ة → ثَلَاثَةٌ ; أ ر ب ع ة → أَرْبَعَةٌ ; س ت ة → سِتَّةٌ ; س ب ع ة → سَبْعَةٌ ; ث م ا ن ي ة → ثَمَانِيَةٌ
  • Exercice 3 : وَاحِدٌ → و - ا - ح - د ; خَمْسَةٌ → خ - م - س - ة ; تِسْعَةٌ → ت - س - ع - ة ; عَشَرَةٌ → ع - ش - ر - ة
  • Exercice 4 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 5 : traductions : 1. un seul livre ; 2. une seule chambre ; 3. un, deux, trois
  • Exercice 6 : وَاحِدٌ ; ثَلَاثَةٌ ; أَرْبَعَةٌ ; سَبْعَةٌ ; عَشَرَةٌ
  • Exercice 7 : وَاحِدٌ = un ; ثَلَاثَةٌ = trois ; أَرْبَعَةٌ = quatre ; خَمْسَةٌ = cinq ; سِتَّةٌ = six ; سَبْعَةٌ = sept ; ثَمَانِيَةٌ = huit ; تِسْعَةٌ = neuf ; عَشَرَةٌ = dix ; اِثْنَانِ = deux
  • Exercice 8 : un = وَاحِدٌ ; trois = ثَلَاثَةٌ ; quatre = أَرْبَعَةٌ ; six = سِتَّةٌ ; neuf = تِسْعَةٌ
