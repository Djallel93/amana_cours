Exercices niveau 3 — Cours 28 : La phrase nominale : le meuble est…

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Prévoyez des temps de jeu à l’oral en plus des exercices écrits, et plusieurs pauses : une page peut se faire en deux fois.

Reconnaître et classer

1Accorder l’adjectifNotion : choix

Choisissez l’adjectif qui s’accorde.

  1. الطَّاوِلَةُ ___
    كَبِيرٌ كَبِيرَةٌ
  2. الْمِصْبَاحُ ___
    جَدِيدٌ جَدِيدَةٌ
  3. الْخِزَانَةُ ___
    قَدِيمٌ قَدِيمَةٌ
  4. الْفِرَاشُ ___
    صَغِيرٌ صَغِيرَةٌ

Construire et déconstruire

3Construire des motsNotion : construction

Assemblez les lettres pour écrire chaque mot, avec ses voyelles.

Sens : armoire

مصباح

Sens : lampe

ثلاجة

Sens : réfrigérateur

4Déconstruire des motsNotion : déconstruction

Séparez le mot en lettres : écrivez chaque lettre isolément, de droite à gauche.

مِرْآةٌ — miroir

سِتَارَةٌ — rideau

وِسَادَةٌ — coussin

تِلْفَازٌ — télévision

6Lire des phrasesNotion : lecture

Lisez chaque phrase à voix haute, puis donnez-en le sens.

Corrigé (enseignant)
  • Exercice 1 : 1. كَبِيرَةٌ ; 2. جَدِيدٌ ; 3. قَدِيمَةٌ ; 4. صَغِيرٌ
  • Exercice 2 : الطَّاوِلَةُ كَبِيرَةٌ (la table est grande) ; الْخِزَانَةُ قَدِيمَةٌ (l’armoire est ancienne) ; الْمِصْبَاحُ جَدِيدٌ (la lampe est neuve)
  • Exercice 3 : ط ا و ل ة → طَاوِلَةٌ ; خ ز ا ن ة → خِزَانَةٌ ; م ص ب ا ح → مِصْبَاحٌ ; ث ل ا ج ة → ثَلَّاجَةٌ
  • Exercice 4 : مِرْآةٌ → م - ر - آ - ة ; سِتَارَةٌ → س - ت - ا - ر - ة ; وِسَادَةٌ → و - س - ا - د - ة ; تِلْفَازٌ → ت - ل - ف - ا - ز
  • Exercice 5 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 6 : traductions : 1. la table est grande ; 2. l’armoire est ancienne ; 3. la lampe est neuve ; 4. la télévision est petite ; 5. ce miroir est neuf
  • Exercice 7 : طَاوِلَةٌ ; خِزَانَةٌ ; مِرْآةٌ ; مِصْبَاحٌ ; تِلْفَازٌ
  • Exercice 8 : الطَّاوِلَةُ كَبِيرَةٌ ; الْخِزَانَةُ قَدِيمَةٌ
  • Exercice 9 : طَاوِلَةٌ = table ; خِزَانَةٌ = armoire ; مِرْآةٌ = miroir ; سِتَارَةٌ = rideau ; مِصْبَاحٌ = lampe ; وِسَادَةٌ = coussin ; ثَلَّاجَةٌ = réfrigérateur ; تِلْفَازٌ = télévision ; مِكْنَسَةٌ = balai ; فِرَاشٌ = matelas
  • Exercice 10 : table = طَاوِلَةٌ ; armoire = خِزَانَةٌ ; lampe = مِصْبَاحٌ ; télévision = تِلْفَازٌ ; balai = مِكْنَسَةٌ
