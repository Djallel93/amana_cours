Exercices niveau 3 — Cours 36 : Faire et jouer : phrases verbales à compléments

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Prévoyez des temps de jeu à l’oral en plus des exercices écrits, et plusieurs pauses : une page peut se faire en deux fois.

Construire et déconstruire

✍️ Pour écrire : Écris chaque mot en entier, de droite à gauche. Ajoute ensuite les points, puis les voyelles et les autres signes. Voir l’aide « Bien écrire ».

1Construire la phraseNotion : construction de phrase

Remettez les mots dans l’ordre pour écrire une phrase.

بِالْكُرَةِلَعِبَالْوَلَدُ
فِيالْبَحْرِالرَّجُلُسَبَحَ
الْمَلْعَبِفِيرَكَضَالطِّفْلُ

2Construire des motsNotion : construction

Assemblez les lettres pour écrire chaque mot, avec ses voyelles.

لعب

Sens : il a joué

سبح

Sens : il a nagé

ركض

Sens : il a couru

رسم

Sens : il a dessiné

كرة

Sens : ballon

3Déconstruire des motsNotion : déconstruction

Séparez le mot en lettres : écrivez chaque lettre isolément, de droite à gauche.

رِحْلَةٌ — voyage

مَلْعَبٌ — terrain de sport

سِبَاحَةٌ — natation

رِيَاضَةٌ — sport

لُعْبَةٌ — jeu

5Lire des phrasesNotion : lecture

Lisez chaque phrase à voix haute, puis donnez-en le sens.

  1. لَعِبَ الْوَلَدُ بِالْكُرَةِ
  2. سَبَحَ الرَّجُلُ فِي الْبَحْرِ
  3. رَكَضَ الطِّفْلُ فِي الْمَلْعَبِ
  4. رَسَمَ الطَّالِبُ الْجَبَلَ

Corrigé (enseignant)
  • Exercice 1 : لَعِبَ الْوَلَدُ بِالْكُرَةِ (le garçon a joué au ballon) ; سَبَحَ الرَّجُلُ فِي الْبَحْرِ (l’homme a nagé dans la mer) ; رَكَضَ الطِّفْلُ فِي الْمَلْعَبِ (l’enfant a couru sur le terrain)
  • Exercice 2 : ل ع ب → لَعِبَ ; س ب ح → سَبَحَ ; ر ك ض → رَكَضَ ; ر س م → رَسَمَ ; ك ر ة → كُرَةٌ
  • Exercice 3 : رِحْلَةٌ → ر - ح - ل - ة ; مَلْعَبٌ → م - ل - ع - ب ; سِبَاحَةٌ → س - ب - ا - ح - ة ; رِيَاضَةٌ → ر - ي - ا - ض - ة ; لُعْبَةٌ → ل - ع - ب - ة
  • Exercice 4 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 5 : traductions : 1. le garçon a joué au ballon ; 2. l’homme a nagé dans la mer ; 3. l’enfant a couru sur le terrain ; 4. l’étudiant a dessiné la montagne
  • Exercice 6 : modèle : رَكَضَ الْوَلَدُ فِي الْمَلْعَبِ
  • Exercice 7 : لَعِبَ ; سَبَحَ ; رَكَضَ ; كُرَةٌ ; رِيَاضَةٌ
  • Exercice 8 : لَعِبَ الْوَلَدُ بِالْكُرَةِ ; سَبَحَ الرَّجُلُ فِي الْبَحْرِ
  • Exercice 9 : لَعِبَ = il a joué ; سَبَحَ = il a nagé ; رَكَضَ = il a couru ; رَسَمَ = il a dessiné ; كُرَةٌ = ballon ; رِحْلَةٌ = voyage ; مَلْعَبٌ = terrain de sport ; سِبَاحَةٌ = natation ; رِيَاضَةٌ = sport ; لُعْبَةٌ = jeu
  • Exercice 10 : il a joué = لَعِبَ ; il a nagé = سَبَحَ ; il a couru = رَكَضَ ; ballon = كُرَةٌ ; sport = رِيَاضَةٌ ; jeu = لُعْبَةٌ
