Exercices niveau 3 — Cours 38 : Un paragraphe : la journée de Youssef

Pour l’enseignant : chaque page d’exercices correspond à un cours. Les exercices de construction et de déconstruction travaillent les lettres et les syllabes ; les exercices de lecture et de dictée utilisent les mots de la séance. Le corrigé se trouve en bas de page (il ne s’imprime pas). Prévoyez des temps de jeu à l’oral en plus des exercices écrits, et plusieurs pauses : une page peut se faire en deux fois.

Lire

4Lire le texteNotion : lecture suivie

Lisez le texte à voix haute, puis répondez aux questions en français.

يُوسُفُ طَالِبٌ. فِي الصَّبَاحِ ذَهَبَ إِلَى الْمَدْرَسَةِ. دَرَسَ الدَّرْسَ وَكَتَبَ فِي الدَّفْتَرِ. فِي الْمَسَاءِ رَجَعَ إِلَى الْبَيْتِ. بَعْدَ الْعَشَاءِ جَلَسَ فِي الْغُرْفَةِ.

  1. Quel est le métier de Youssef ?
  2. Où va-t-il le matin ?
  3. Que fait-il en classe ?
  4. Où est-il le soir ?

Corrigé (enseignant)
  • Exercice 1 : فِي الصَّبَاحِ ذَهَبَ إِلَى الْمَدْرَسَةِ (le matin, il est allé à l’école) ; فِي الْمَسَاءِ رَجَعَ إِلَى الْبَيْتِ (le soir, il est rentré à la maison)
  • Exercice 2 : ص ب ا ح → صَبَاحٌ ; م س ا ء → مَسَاءٌ ; ف ط و ر → فُطُورٌ ; غ د ا ء → غَدَاءٌ ; ع ش ا ء → عَشَاءٌ
  • Exercice 3 : رَاحَةٌ → ر - ا - ح - ة ; إِلَى → إ - ل - ى ; رَجَعَ → ر - ج - ع ; بَعْدَ → ب - ع - د ; قَبْلَ → ق - ب - ل
  • Exercice 4 : traduction : Youssef est étudiant. Le matin, il est allé à l’école. Il a étudié la leçon et il a écrit dans le cahier. Le soir, il est rentré à la maison. Après le dîner, il s’est assis dans la chambre. — réponses : 1. étudiant ; 2. à l’école ; 3. il étudie la leçon et écrit dans le cahier ; 4. à la maison
  • Exercice 5 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 6 : traductions : 1. le matin, il est allé à l’école ; 2. le soir, il est rentré à la maison
  • Exercice 7 : production libre : vérifier les voyelles, les liaisons et la ponctuation.
  • Exercice 8 : صَبَاحٌ ; مَسَاءٌ ; فُطُورٌ ; غَدَاءٌ ; رَجَعَ
  • Exercice 9 : صَبَاحٌ = matin ; مَسَاءٌ = soir ; فُطُورٌ = petit-déjeuner ; غَدَاءٌ = déjeuner ; عَشَاءٌ = dîner ; رَاحَةٌ = repos ; إِلَى = vers ; رَجَعَ = il est revenu ; بَعْدَ = après ; قَبْلَ = avant
  • Exercice 10 : matin = صَبَاحٌ ; soir = مَسَاءٌ ; petit-déjeuner = فُطُورٌ ; déjeuner = غَدَاءٌ ; il est revenu = رَجَعَ ; après = بَعْدَ
