  • Exercice 2 : 1. قِطَارًا ; 2. سَيَّارَةً ; 3. مَقْهًى ; 4. شَارِعًا
  • Exercice 3 : هَٰذَا ; سَلَامٌ ; لَٰكِنْ ; هِلَالٌ
  • Exercice 4 : lecture à voix haute, avec correction de la prononciation par l’enseignant.
  • Exercice 5 : س ق ف → سَقْفٌ ; ه م → هُمْ ; ع ل ى → عَلَى ; ل ي ل ى → لَيْلَى
  • Exercice 6 : مَنْ → م - ن ; مَطَارٌ → م - ط - ا - ر ; قِطَارٌ → ق - ط - ا - ر ; هَٰذَا → ه - ذ - ا
  • Exercice 7 : مَلَاكٌ ; مُوسَى ; لَا ; دَرَّاجَةٌ ; هِلَالٌ
  • Exercice 8 : لَا = non ; مَدْرَسَةٌ = école ; دَرَّاجَةٌ = vélo ; مُعَلِّمَةٌ = enseignante ; صَدِيقَةٌ = amie ; مَطْبَخٌ = cuisine
  • Exercice 9 : ceci (masc.) = هَٰذَا ; la plus petite = صُغْرَى ; jardin = حَدِيقَةٌ ; parole = كَلَامٌ ; étudiante = طَالِبَةٌ
