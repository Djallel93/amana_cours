Le vocatif

النِّدَاءُ
🔗 Prérequis : les cours sur les phrases interrogatives et sur l'annexion.
Le vocatif sert à appeler quelqu'un : « Ô Ahmed ! », « Ô mon ami ! ». On utilise la particule يَا.

📣 Appeler quelqu'un

يَا + le nom, sans ال et sans tanwīn. Le nom seul prend une ḍamma. Si le nom est suivi d'un complément (annexion), il prend une fatḥa.

CasExempleSens
nom propreيَا أَحْمَدُÔ Ahmed !
nom seulيَا مُعَلِّمُÔ enseignant !
nom + complémentيَا مُعَلِّمَ الصَّفِّÔ enseignant de la classe !
avec monيَا صَدِيقِيÔ mon ami !

🔹 Appeler un nom avec ال

On intercale أَيُّهَا (masculin) ou أَيَّتُهَا (féminin) entre يَا et le nom.

📝 Exemples :

  • يَا أَيُّهَا الطَّالِبُ → Ô élève !
  • يَا أَيَّتُهَا الطَّالِبَةُ → Ô élève (fille) !
  • يَا أَيُّهَا الطُّلَّابُ، اِسْمَعُوا → Ô élèves, écoutez !
📚 Je retiens :
  • يَا + nom sans ال : ḍamma, ou fatḥa si le nom est annexé.
  • Avec ال : يَا أَيُّهَا / يَا أَيَّتُهَا.
