Les nombres ordinaux

الْأَعْدَادُ التَّرْتِيبِيَّةُ
🔗 Prérequis : les cours sur les nombres cardinaux et sur l'accord des nombres.
Les ordinaux (premier, deuxième…) sont des adjectifs. Ils suivent le nom et s'accordent avec lui.

🎯 De 1er à 10e

À partir de 3, le masculin se forme sur le modèle فَاعِلٌ : ثَالِثٌ, رَابِعٌ, خَامِسٌ…

💬 Dans une phrase

📝 Exemples :

  • أَنَا فِي الصَّفِّ السَّابِعِ → Je suis en classe de cinquième.
  • الْحِصَّةُ الثَّالِثَةُ → le troisième cours
  • هَذَا الْيَوْمُ الْأَوَّلُ فِي الْمَدْرَسَةِ → C'est le premier jour à l'école.

📚 Je retiens :
  • L'ordinal suit le nom et s'accorde avec lui.
  • Il prend ال si le nom est défini.
  • Le féminin se termine par ة.
