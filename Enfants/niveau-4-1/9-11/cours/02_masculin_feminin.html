Le masculin et le féminin

الْمُذَكَّرُ وَالْمُؤَنَّثُ
🔗 Prérequis : le cours sur le défini et l'indéfini ; niveau 3 : la lettre ة.
En arabe aussi, les mots sont masculins ou féminins. Le plus souvent, pour passer au féminin, on ajoute ة à la fin.

🎯 Féminin = masculin + ة

MasculinFémininSens
صَدِيقٌصَدِيقَةٌun ami / une amie
طَالِبٌطَالِبَةٌun élève / une élève
مُعَلِّمٌمُعَلِّمَةٌun enseignant / une enseignante
كَبِيرٌكَبِيرَةٌgrand / grande
صَغِيرٌصَغِيرَةٌpetit / petite

🤝 L'adjectif prend le genre du nom

Quand le nom est féminin, l'adjectif qui le décrit est féminin aussi.

📝 Exemples :

  • صَدِيقٌ طَيِّبٌ → un bon ami
  • صَدِيقَةٌ طَيِّبَةٌ → une bonne amie
  • الطَّالِبَةُ مُجْتَهِدَةٌ → L'élève est travailleuse.
  • هَذِهِ مَدْرَسَةٌ كَبِيرَةٌ → C'est une grande école.

⭐ Des mots féminins sans ة

Quelques mots sont féminins sans avoir ة. Il faut les apprendre : أُمٌّ (mère), أُخْتٌ (sœur), بِنْتٌ (fille).

📚 Je retiens :
  • Féminin = masculin + ة.
  • L'adjectif suit le genre du nom.
  • Quelques mots féminins n'ont pas ة.
