Les formes du pluriel en arabe

الجَمْع
Bienvenue dans ce cours sur le pluriel en arabe !
En arabe, le pluriel présente des particularités fascinantes et uniques. Contrairement au français qui ajoute généralement un "-s", l'arabe dispose de deux systèmes distincts : le pluriel régulier (appelé aussi "pluriel sain") et le pluriel irrégulier (appelé "pluriel brisé"). Ce cours vous guidera à travers ces deux formes avec clarté et simplicité.

📚 Les deux types de pluriel / نَوْعا الجَمْع

Il existe deux types principaux de pluriel en arabe :

  • Le pluriel régulier (الجَمْعُ السالِمُ) : formation prévisible par ajout de suffixes
  • Le pluriel brisé (جَمْعُ التَكْسِيرِ) : formation irrégulière avec modification interne du mot

👨 Le pluriel masculin régulier / جَمْعُ المُذَكَّرِ السالِم

Pour former le pluriel masculin régulier, on remplace les terminaisons du singulier par ces deux suffixes :

  • Cas sujet (مَرْفُوع) : ـونَ /ūna/
  • Cas direct (مَنْصوب) et indirect (مَجْرور) : ـِينَ /īna/

📝 Modifications spécifiques :
  • Pour les mots se terminant par اء : la hamza reste
    Exemple : بَنّاءٌ ← بَنّاؤُونَ / بَنّائِينَ (maçon → maçons)
  • Pour les mots se terminant par ى : l'alif disparaît mais la fatḥa reste
    Exemple : مُغَطًّى ← مُغَطَّونَ / مُغَطَّينَ (couvert → couverts)
  • Pour les participes actifs de verbes faibles : le kasra final et le ي disparaissent
    Exemple : راضٍ ← راضُونَ / راضِينَ (satisfait → satisfaits)

👩 Le pluriel féminin régulier / جَمْعُ المُؤَنَّثِ السالِم

Pour former le pluriel féminin régulier, on remplace les terminaisons du singulier (en enlevant le ة s'il est présent) par :

  • Cas sujet (مَرْفُوع) : ـاتٌ /ātun/
  • Cas direct (مَنْصوب) et indirect (مَجْرور) : ـاتٍ /ātin/

مَلِكاتٌ مَلِكاتٍ مَلِكةٌ

مُعَلِّماتٌ مُعَلِّماتٍ مُعَلِّمةٌ

طالِباتٌ طالِباتٍ طالِبةٌ

🔍 Transformations particulières :

Pour les noms se terminant par ى, اة ou اء : ces terminaisons sont remplacées par un و ou un ي

  • قَناة ← قَنَوات (canal → canaux)
  • حَياة ← حَيَوات (vie → vies)
  • سَماء ← سَمَاوات (ciel → cieux)

أَخَوات أُخْت (sœur)

💫 Le pluriel brisé (irrégulier) / جَمْعُ التَكْسِير

Le pluriel brisé est une caractéristique unique de l'arabe. Il fonctionne comme les pluriels irréguliers en français (par exemple : "œil → yeux", "cheval → chevaux"). La formation se fait par des modifications internes du mot plutôt que par simple ajout de suffixes.
⚠️ Point important : Il n'existe pas de règle absolue pour créer des pluriels brisés à partir des mots singuliers. Certains mots peuvent avoir plusieurs formes de pluriel. Le pluriel brisé est utilisé plus fréquemment que le pluriel régulier en arabe.
💡 Conseil pratique : Lors de l'apprentissage d'un nouveau mot en arabe, il est essentiel de mémoriser simultanément sa forme au singulier ET au pluriel. Avec l'exposition à la langue, ces formes se mémorisent naturellement.

🧠 La notion de "doué de raison" / العاقِل

En arabe, il existe une distinction importante entre les êtres doués de raison (العاقِل) et ceux qui ne le sont pas (غَيْر العاقِل). Cette distinction influence le choix du type de pluriel à utiliser.
📌 Définition :
  • Doués de raison (العاقِل) : les êtres humains (hommes, femmes, enfants)
  • Non doués de raison (غَيْر العاقِل) : les animaux, les objets, les plantes, les concepts abstraits

Règles d'utilisation du pluriel selon cette distinction

Pour les êtres humains (doués de raison) :
  • Masculin : on utilise généralement le pluriel masculin régulier ـون / ـين
  • Féminin : on utilise généralement le pluriel féminin régulier ـات

💡 Exemples pour les êtres doués de raison :

  • مُعَلِّم ← مُعَلِّمون (enseignant → enseignants) - pluriel régulier
  • طالِبة ← طالِبات (étudiante → étudiantes) - pluriel régulier
  • طَبِيب ← أَطِبّاء (médecin → médecins) - pluriel brisé également possible
Pour les êtres non doués de raison :
  • On utilise généralement le pluriel brisé
  • Ces pluriels sont traités grammaticalement comme des féminins singuliers dans les accords

💡 Exemples pour les êtres non doués de raison :

  • كِتاب ← كُتُب (livre → livres) - pluriel brisé
  • حَيَوان ← حَيَوانات (animal → animaux) - pluriel féminin régulier
  • شَجَرة ← أَشْجار (arbre → arbres) - pluriel brisé

🎯 Comment choisir entre pluriel régulier et pluriel brisé ?

Principes généraux :
  • Pluriel masculin régulier : souvent utilisé pour les noms de métiers, les participes actifs et certains adjectifs masculins
  • Pluriel féminin régulier : principalement pour les entités humaines féminines et certains noms non-humains
  • Pluriel brisé : très fréquent, utilisé pour la majorité des noms (objets, animaux, concepts abstraits) et certains humains

💡 Exemples comparatifs :

  • Entités humaines masculines : souvent pluriel régulier
    مُعَلِّم ← مُعَلِّمون (enseignant → enseignants)
  • Entités humaines féminines : souvent pluriel régulier
    مُعَلِّمة ← مُعَلِّمات (enseignante → enseignantes)
  • Objets et concepts : généralement pluriel brisé
    كِتاب ← كُتُب (livre → livres)
⚠️ Attention : Certains mots peuvent avoir à la fois une forme de pluriel régulier ET une forme de pluriel brisé, parfois avec des nuances de sens différentes !

📝 Résumé de la leçon

  • L'arabe possède deux types principaux de pluriel : régulier et brisé
  • Le pluriel masculin régulier utilise les suffixes ـون (cas sujet) et ـين (autres cas)
  • Le pluriel féminin régulier utilise les suffixes ـات (avec tanwīn selon le caractère défini/indéfini)
  • Le pluriel brisé modifie la structure interne du mot selon de nombreuses transformations différentes
  • La distinction entre doués de raison (êtres humains) et non doués de raison (animaux, objets) influence le choix du pluriel
  • Pour les êtres humains, on utilise généralement les pluriels réguliers
  • Pour les animaux et objets, on utilise généralement le pluriel brisé
  • Il est essentiel de mémoriser chaque nom avec sa forme plurielle lors de l'apprentissage
  • Le pluriel brisé est plus fréquent en arabe que le pluriel régulier
