📝 Exercices Pratiques

تَمَارِين الضَّمائِر
👋 Instructions : Complétez les exercices suivants pour pratiquer les pronoms arabes. Rappelez-vous : les pronoms arabes sont indéclinables (ne changent pas de forme). Il existe deux catégories : les pronoms détachés (sujets indépendants) et les pronoms affixes (suffixes attachés aux noms, verbes ou prépositions).

4Pronoms affixes attachés aux noms (possession)

Attachez le pronom affixe au nom كِتاب (livre)

  1. mon livre → كِتاب + ـي =
  2. ton livre (masc.) → كِتاب + ـكَ =
  3. son livre (à lui) → كِتاب + ـهُ =
  4. son livre (à elle) → كِتاب + ـهَا =
  5. notre livre → كِتاب + ـنَا =
  6. votre livre (masc. pl.) → كِتاب + ـكُم =
💡 Exemple en phrase : نَظَرْتُ إِلى جُرْحِكَ = J'ai regardé ta blessure.

5Pronoms affixes attachés aux verbes (COD)

Attachez le pronom affixe au verbe رَأَى (voir, passé 1ère pers. sg.)

Rappel : رَأَيْتُ + pronom = COD du verbe

  1. Je l'ai vu (lui) → رَأَيْتُ + ـهُ =
  2. Je l'ai vue (elle) → رَأَيْتُ + ـهَا =
  3. Je les ai vus (eux) → رَأَيْتُ + ـهُم =
  4. Il m'a vu → رَأَى + ـنِي =
  5. Il nous a aidés → سَاعَدَ + ـنَا =
  6. Il les a remerciés → شَكَرَ + ـهُم =
⚠️ Règle spéciale : Le pronom de 1ère personne du singulier (ـي) attaché à un verbe prend un نُون de protection → ـنِي.
Exemple : لَكَمَ + ـي = لَكَمَنِي (Il m'a donné un coup de poing)

6Pronoms affixes attachés aux prépositions

Combinez les prépositions avec les pronoms affixes

  1. لِ + lui →
  2. لِ + elle →
  3. لِ + toi (masc.) →
  4. مَعَ + lui →
  5. عِنْدَ + elle →
  6. بِ + eux →
  7. مِنْ + moi →
  8. عَنْ + moi →
⚠️ Règles spéciales :
  • Préposition لِ : sa kasra devient une fatḥa → لَهُ، لَكَ (sauf pour ـي → لِي)
  • مِنْ + ـي = مِنِّي / عَنْ + ـي = عَنِّي (ajout du نُون)

7Pronoms affixes : 3ème pers. — kasra ou ḍamma ?

Choisissez la forme correcte du pronom de 3ème personne

Rappel : le pronom ـهُ devient ـهِ après un cas génitif ou un ي

  1. الكِتَابُ في بَيْتِ______ → ـهُ ou ـهِ ? →
    (Le livre est dans sa maison → بَيْت est au génitif)
  2. رَأَيْتُ______ → ـهُ ou ـهِ ? →
    (Je l'ai vu → après verbe à l'accusatif)
  3. في______ → ـهُم ou ـهِم ? →
    (Parmi eux → après préposition)
  4. كِتابِي______ → ـهُ ou ـهِ ? →
    (Après un mot terminant par ي)

10Vrai ou faux ?

Indiquez si les affirmations sont vraies (V) ou fausses (F)

  1. Les pronoms arabes changent de forme selon leur cas grammatical
  2. Les pronoms détachés s'utilisent principalement comme sujets
  3. هُمُ devient هُمُ devant l'article défini
  4. Le pronom de 1ère pers. sg. ـي prend un نُون de protection avec les verbes
  5. Le pronom ـهُ reste toujours avec ḍamma quelle que soit sa position
  6. Les pronoms affixes attachés aux noms ont une fonction possessive
  7. أَنْتِ est le pronom de la 2ème personne féminin singulier
  8. هُما désigne exclusivement deux personnes masculines

11Trouvez l'erreur

Corrigez les erreurs dans les phrases suivantes

  3. لَكَمَيْ (Il m'a frappé — sans نُون de protection) →
  4. مِنْي (De moi — sans نُون) →
  5. هُم الناجِحُونَ (Eux, les gagnants — sans ḍamma de liaison) →

12Exercice de compréhension

Lisez et répondez

هُوَ طالِبٌ في الجامِعَةِ. كِتابُهُ كَبِيرٌ. رَأَيْتُهُ أَمْسِ. تَحَدَّثْتُ مَعَهُ عَنْ دَرْسِهِ.

(Il est étudiant à l'université. Son livre est grand. Je l'ai vu hier. J'ai parlé avec lui de sa leçon.)

Questions :

  1. Combien de pronoms affixes y a-t-il dans ce texte ?
  2. Quel pronom détaché est utilisé ?
  3. Dans كِتابُهُ, le pronom ـهُ a quelle fonction ?
  4. Dans رَأَيْتُهُ, le pronom ـهُ a quelle fonction ?
  5. Dans مَعَهُ, le pronom ـهُ est attaché à quelle partie du discours ?
💡 Conseil : Pour mémoriser les pronoms, pratiquez régulièrement en construisant des phrases avec chaque personne. Commencez par les pronoms détachés (sujets), puis exercez-vous aux pronoms affixes en les attachant aux noms, verbes et prépositions.
🎯 Objectifs atteints : Après avoir complété ces exercices, vous devriez être capable d'identifier et d'utiliser correctement les pronoms détachés et affixes arabes dans leurs trois fonctions (possession, COD, complément de préposition). Félicitations ! 🎉
