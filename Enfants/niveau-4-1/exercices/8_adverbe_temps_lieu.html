تَمَارِين ظُرُوف الزَّمَان وَالمَكَان
👋 Instructions : Complétez les exercices suivants pour pratiquer les adverbes de temps et de lieu en arabe. Rappelez-vous : les adverbes déclinables (مُعْرَب) changent leur terminaison selon la fonction grammaticale, tandis que les adverbes indéclinables (مَبْنِيّ) restent toujours identiques.

2Adverbes de lieu — Où est-ce ?

Complétez avec le bon adverbe de lieu

Utilisez : أَمَامَ / خَلْفَ / فَوْقَ / تَحْتَ / بَيْنَ / حَوْلَ / عِنْدَ / وَسْطَ

  1. الكِتَابُ ______ الطَّاوِلَةِ → Le livre est sur la table
  2. القِطَّةُ ______ السَّرِيرِ → Le chat est sous le lit
  3. جَلَسَ الطَّالِبُ ______ المُعَلِّمِ → L'étudiant s'est assis devant le professeur
  4. المَكْتَبَةُ ______ المَسْجِدِ → La bibliothèque est derrière la mosquée
  5. الحَدِيقَةُ ______ المَبْنَيَيْنِ → Le jardin est entre les deux bâtiments
  6. الأَشْجَارُ ______ البَيْتِ → Les arbres sont autour de la maison
  7. وَقَفَ ______ المَيْدَانِ → Il s'est arrêté au milieu de la place
  8. أَنَا ______ صَدِيقِي → Je suis chez mon ami

Traduisez les phrases suivantes en arabe en utilisant : هُنَا / هُنَاكَ / أَيْنَ / حَيْثُ / لَدَى

  1. Où est la clé ? →
  2. La clé est ici →
  3. Le bureau est là-bas →
  4. Assieds-toi où tu veux →
  5. Il a des informations importantes →

4Adverbes de temps — Quand ?

Complétez avec le bon adverbe de temps

Utilisez : قَبْلَ / بَعْدَ / حِينَ / أَثْنَاءَ / فَوْرَ / بَيْنَمَا / لَمَّا / مُنْذُ

  1. ______ الدَّرْسِ، دَخَلَ المُدِيرُ → Pendant le cours, le directeur est entré
  2. ______ وَصَلَ، اتَّصَلَ بِي → Dès qu'il est arrivé, il m'a appelé
  3. سَأَذْهَبُ ______ الدَّرْسِ → J'irai après le cours
  4. جَاءَ ______ الغُرُوبِ → Il est venu avant le coucher du soleil
  5. ______ كُنْتُ أَدْرُسُ، دَخَلَ أَخِي → Tandis que j'étudiais, mon frère est entré
  6. ______ انْتَهَى الدَّرْسُ، خَرَجْنَا → Quand le cours s'est terminé, nous sommes sortis
  7. ______ سَاعَةٍ أَنْتَظِرُ → J'attends depuis une heure
  8. جِئْتُ ______ وُصُولِهِ → Je suis venu au moment de son arrivée

Identifiez l'adverbe qui convient et expliquez pourquoi il est indéclinable

  2. Je n'ai jamais fait cela →
  3. Je suis occupé maintenant →
  4. Quand viendras-tu ? →
  5. Tandis que tu dormais, il est parti →

6Exprimer la possession avec عِنْدَ et لَدَى

Construisez des phrases pour exprimer "avoir" en arabe

Rappel : عِنْدَ = courant ; لَدَى = formel/littéraire

  1. J'ai une voiture → (avec عِنْدَ)
  2. As-tu du temps ? → (avec عِنْدَ)
  3. Elle a un nouveau livre →
  4. Le médecin a une grande expérience → (avec لَدَى)
  5. Nous avons un projet important → (avec لَدَى)
  6. Sara a un beau chat →
⚠️ Rappel : Quand لَدَى est suivi d'un pronom, il devient لَدَيْـ : لَدَيَّ، لَدَيْكَ، لَدَيْهِ

9Vrai ou faux ?

Indiquez si les affirmations sont vraies (V) ou fausses (F)

  1. أَمْسِ garde toujours la kasra finale, quelle que soit sa position
  2. Les adverbes déclinables sont généralement à l'accusatif (fatḥa) quand ils fonctionnent seuls
  3. هُنَا peut changer de forme selon les cas grammaticaux
  4. Quand un adverbe déclinable est suivi d'un nom, ils forment une annexion (إِضَافَة)
  5. عِنْدَ et لَدَى peuvent exprimer la possession
  6. قَطُّ s'utilise pour nier une action au futur
  7. Les adverbes répondent aux questions أَيْنَ؟ ou مَتَى؟

10Dialogue : À la maison

Complétez le dialogue avec les adverbes corrects

B : وَصَلَ ______ (Il est arrivé hier)

B : نَعَمْ ______ سَيَّارَةٌ جَدِيدَةٌ (Oui, j'ai une nouvelle voiture)

11Trouvez l'erreur

Chaque phrase contient une erreur. Corrigez-la :

  1. رَأَيْتُهُ أَمْسَ (hier, avec fatḥa) →
  2. جَلَسَ فَوْقُ الطَّاوِلَةِ (avec ḍamma) →
  3. ما فَعَلْتُ ذٰلِكَ قَطَّ (avec fatḥa) →
  4. عِنْدَهُ عِلْمٌ كَبِيرَةٌ (erreur d'accord) →
  5. أَيْنَ الْكِتَابُ؟ هُوَ هُنَاكَ (réponse correcte pour un objet visible proche) →

💡 Conseil : Pour bien distinguer les adverbes de lieu et de temps, posez-vous toujours la question : est-ce que cet adverbe répond à أَيْنَ؟ (où ?) ou à مَتَى؟ (quand ?). Et pour la déclinabilité : les adverbes anciens ou qui ont perdu leur flexion naturelle sont indéclinables (comme أَمْسِ).
