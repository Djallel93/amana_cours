Le nom d'action et les noms de lieu

الْمَصْدَرُ وَاسْمُ الْمَكَانِ
🔗 Prérequis : les cours sur la forme I et sur les dix formes.
Le nom d'action (le مَصْدَرٌ) est le nom qui désigne une action : « l'écriture », « la lecture ». Il permet aussi de fabriquer des noms de lieu.

1️⃣ Le nom d'action

VerbeNom d'actionSens
كَتَبَكِتَابَةٌl'écriture
قَرَأَقِرَاءَةٌla lecture
ذَهَبَذَهَابٌl'aller
دَخَلَدُخُولٌl'entrée
جَلَسَجُلُوسٌle fait de s'asseoir
💡 À savoir : à la forme I, le nom d'action n'a pas de règle unique : on l'apprend avec le verbe. Aux formes augmentées, il est régulier (تَعْلِيمٌ, إِرْسَالٌ).

2️⃣ Le nom d'unité : « une fois »

Le schème فَعْلَةٌ désigne une seule action : ضَرْبَةٌ (un coup), نَظْرَةٌ (un regard), خَطْوَةٌ (un pas).

3️⃣ Les noms de lieu

On place مَـ devant la racine : مَفْعَلٌ (ou مَفْعِلٌ quand le présent est en كَسْرَةٌ).

VerbeLieuSens
كَتَبَ ـ يَكْتُبُمَكْتَبٌbureau
لَعِبَ ـ يَلْعَبُمَلْعَبٌterrain de jeu
طَبَخَ ـ يَطْبُخُمَطْبَخٌcuisine
جَلَسَ ـ يَجْلِسُمَجْلِسٌsalon
نَزَلَ ـ يَنْزِلُمَنْزِلٌdomicile
سَجَدَ ـ يَسْجُدُمَسْجِدٌmosquée

Avec ـَةٌ, le lieu est habituel : مَدْرَسَةٌ (école), مَكْتَبَةٌ (bibliothèque).

🔧 Les outils : le schème مِفْعَالٌ désigne un instrument : مِفْتَاحٌ (clé, de فَتَحَ) ; مِكْنَسَةٌ (balai).
📚 Je retiens :
  • Le nom d'action de la forme I s'apprend avec le verbe.
  • Lieu : مَفْعَلٌ / مَفْعِلٌ. Instrument : مِفْعَالٌ.
